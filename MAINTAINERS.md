## English statement for project verification

The GitHub account [ywyz](https://github.com/ywyz) owns and maintains [kindergarten-manager-next](https://github.com/ywyz/kindergarten-manager-next). The maintainer is responsible for the project's product decisions, review and releases. Development and verification are assisted by AI tools.

This is a personal open-source project for kindergarten teachers. The current desktop source baseline is the default [`main`](https://github.com/ywyz/kindergarten-manager-next/tree/main) branch; active development uses [`dev/0.1`](https://github.com/ywyz/kindergarten-manager-next/tree/dev/0.1), documentation uses the [`docs`](https://github.com/ywyz/kindergarten-manager-next/tree/docs) branch, preview-update fixes use [`fix/preview-update`](https://github.com/ywyz/kindergarten-manager-next/tree/fix/preview-update), and historical `codex/*` branches are retained; `fix/<issue>` is the naming rule. The public signed preview is `v0.1.0-listening-test.20261114`; a stable signed release is not yet available. Original project content is licensed under the [MIT License](LICENSE); third-party materials retain their respective licenses. The project currently has no commercial distribution plan and is being verified from source.
