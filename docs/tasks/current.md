## 连续实施顺序

| 阶段 | 原生 OpenCode 交付 | Codex 放行下一段的证据 |
| --- | --- | --- |
| **L1　模板、记录、照片与备份** | 清理空表副本的个人属性、检查外链，登记小／中／大班各五张的版本、散列及逐档评价原文。同年级上下学期共用标准。核实际迁移头，从 `20261102_0008_local_weekly_ai` 合成旧库验证升级。实现手填姓名、一人五表、每领域三个稳定图文位置、可空单选星级、保存修订与重试回执。让倾听照片进入完整备份的登记、校验、恢复链路。 | 在新库和升级后的合成库经正常本地服务入口读写。给两名同名幼儿分别存五张表和不同照片，核对跨记录隔离、换序／替换、拒绝第四张、旧修订冲突和同请求重试。完整备份恢复到独立新根，用新的源码进程冷开，逐项比对字段、空星级、模板版本及照片散列。旧备份仍能恢复；破坏副本图片、路径或迁移时，明确失败并保护原库。 |
| **L2　教师手工填写** | 从源码工作台按班级、学期进入记录列表，新建时手填姓名，期末连续填写五个领域。接通三组日期、照片、右栏正文、逐项星级、综合评价、支持策略，以及切表、切人、离页、关闭前保存。 | 从源码桌面入口走“新建 → 填写 → 补图 → 切表 → 关闭 → 独立重开”。验证同名记录可区分、迟到响应不会串人、取消选图零写入、写入失败留页保稿；无 AI 配置也能完成。 |
| **L3　两种 Word 合册** | 从已保存的同一份资料生成两种 Word。按幼儿合五领域；按领域默认勾选本班本学期全部已建记录，可部分勾选、手动调序。集中提示所选记录缺项，确认后在原格留空。接通原生另存为和结果回执。 | 从源码页面实际导出个人和领域合册，在 Microsoft Word 看实际页面。检验 15 份受控模板的结构及评价原文；以已通过的中班两份样稿对照图文、勾选、缺图与空星级。右栏倾听正文须为纯黑宋体小四（12 磅）、常规字重；领域名称与左右留白连续加黑色单下划线，其余文字纯黑、图片保留原色。再核长文、横竖图、取消和保存失败。15／9 页仅是原合成样稿的结果。 |
| **L4　AI 候选、采用与全程联测** | 接通两个独立的主动操作。① 整理本组右栏：仅有作品照片也能生成供教师改写的草案，标明仅图来源，不虚构幼儿原话。② 根据本领域已保存资料和空表标准，同时生成**综合评价、支持策略、逐项星级建议**。两段文字分别采用，星级由教师逐项确认、改选或跳过。 | 仅用假供应商验证文本与视觉任务，核输入归属、仅图起草、保存失败零发送、超时／结果不明不自动重发、拒绝过期候选和重复采用。只采用支持策略并改选一项星级后，保存、重开并从两种 Word 导出，核对只出现教师已保存的选择。未采用候选、已采用正文及星级在备份恢复后仍能区分。 |

L1 可从[本地模型](../../backend/app/local/models.py)、[照片导入](../../backend/app/local/observation_assets.py)、[备份资源枚举](../../backend/app/local/backup_validate.py)与[完整快照](../../backend/app/local/backup_snapshot.py)入手。优先复用已有的事务、根锁、文件屏障及回执；新增倾听资源须有自己的归属。只对当段受影响的模块补测试，不提前改下一段的共享入口。

## 自动接续与最终交付

1. 每段先由实现者提交工作摘要、确切文件、命令与测试回执；Codex 从另一份合成资料独立复核。可复现的缺陷在原责任内回修，保留首次失败，复测实际修订后的字节。通过后直接进入下一段，无需教师逐轮批准。只有确认缺少必要输入、已有工作冲突无法安全整合，或需要新的产品决定／权限时，才提出具体问题；可独立的工作继续。
2. 四段完成后用一套可追踪的虚构资料串起工作台建档、三组图文、AI 仅图草案、两段评价文字、逐项确认星级、选择／调序、两种 Word、备份恢复和独立冷开。自动测试、源码窗口、实际 Word 页检和教师体验分别记。任何未执行项写明原因，便携包排除项不算通过或失败。
3. **一次性交给教师**：一份短验收清单、源码应用实际生成的两份可编辑 Word、代表页预览，以及哪些流程已通过、哪些仍未验。原生实现者不代签教师意见。教师本轮另明确授权付费应用 AI 验证：L4 先完成假供应商验证，再使用既有标准供应商配置进行必要的文本／视觉实测；结果不明不自动重发，配置持久保留，不回显密钥。允许调用 OpenCode 和 Command Go，仍遵守唯一写入者与核查责任。Git 依当轮明确授权与精确文件、blob、parent、tree 门禁执行；本轮不启动签名、发行或远程部署。
