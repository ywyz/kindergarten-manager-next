# ADR 0005　可选的同班在线协作

2026-11-08，教师确认首段在线协作的班级规则为「由教师选择班级，班级相同系统自动配对」。先做 #5、#8 的在线班级和配置带入服务，数据库验证暂缓。适用 [教师手测反馈 #5、#8](../specs/desktop-teacher-feedback-repair.md#第六批搭班协作与在线数据库)。[ADR 0004](0004-local-desktop-architecture-proposal.md) 继续规定本地桌面。共享周计划仍为提议。

## 提议

- 桌面提供「本地 SQLite」和「在线协作」两个明确入口。本地模式继续由单个本地教师档案和 SQLite 提供原有功能。在线模式的共享数据以服务端为权威。桌面通过 HTTPS 业务 API 登录和操作。服务端在私网通过标准 PostgreSQL 驱动连接数据库，由部署侧配置连接信息。
- 班级使用稳定标识，服务端用已确认的班级成员关系限制配置、周计划和来源版本读取。带入搭班老师的班级游戏配置先显示来源和差异，教师确认才写本人配置。来源版本变化时重新预览。
- 共享周计划保存使用显式基准版本和事务。并发提交发生冲突时返回可识别的当前版本，保留教师尚未提交的输入，供教师决定如何合并。确认快照继续作为导出依据。断网时明确显示在线状态，在线对象的未提交内容继续可见。在线对象只在在线模式写入。
- 首期的拟共享范围是班级游戏配置和协作所需的周计划字段。幼儿档案、照片、个人记录、个人 AI 指导和供应商密钥留在本地。模式切换与显式的数据迁移分别操作，已有本地资料保持原有归属。
- 工程阶段先实现经确认的业务路径与数据库边界。中国大陆供应商由教师比选。云库开通、供应商兼容性与备份恢复测试、线上联调和生产数据迁移另行安排。数据库和 API 主机在选定后按同地域私网部署。

## 实施前需确认的产品决定

1. 共享周计划的具体字段、来源日计划可见范围、候选归属和哪位教师可确认。
2. 共享周计划发生并发冲突后教师如何处理，以及本地已有数据是否允许主动导入在线模式。

## 首段班级和配置带入合同

- 在线账号由服务认证并绑定一个园所。教师从该园所的系统班级列表选择稳定班级 ID，选择相同 ID 的教师自动成为同班成员。换班后原班关系立即失效。班名仅用于显示，允许同名班级和升班改名。首段由服务部署方准备账号和班级目录，教师自己选择，双方无需另发邀请。
- 班级游戏配置按园所、班级和教师归属。教师可以保存自己的在线配置，并读取当前同班教师已保存的配置。读、预览及确认均由服务端重新检查成员关系。在线服务只接受地点、游戏范围和班级游戏指导等班级配置字段。
- 带入分预览与确认。预览展示对方姓名、来源版本、本人基准版本和配置差异。确认绑定原始预览的来源、两个版本及原请求 ID，事务内再次检查成员与版本，只写本人该班的配置。原请求可重试并查询回执。取消预览无需服务端写入，来源或本人版本变动须重新预览。
- 桌面首段由部署方配置 HTTPS 业务地址并发放教师凭据，凭据限本次桌面进程。教师主动连接。需要发布已有本地班级游戏配置时，先在界面核对目标在线班级、在线基准版本及将发布的字段，再明确确认。教师处理未知结果时，用原园所和原账号恢复连接，查询原请求。在线配置和本地配置分别管理。
- 先提供独立 FastAPI 服务、PostgreSQL 模型和建库定义，形成桌面接入所需的业务 API。部署、账号实际开通、选择云厂商、连接数据库以及运行数据库测试另行安排。共享周计划等产品决定确认后再继续该段。

## 管理端和教师桌面流程

2026-11-08 教师确认管理端使用管理员账号。管理员为教师首次加入和换机恢复分别签发一次性码。以下规则用于后续接入，首段验证仍按上节记录。

- 加入码绑定教师身份和园所。兑换后教师在桌面端自主选班，继续按稳定班级 ID 自动配对。
- 恢复码绑定原教师 ID。服务端在兑换后读取该身份已有且仍有效的班级关系，桌面端直接进入原班。
- 班级成员在桌面端自主发起并确认升班。服务端按班级版本提交一次变更，沿用班级 ID 和成员关系。确认快照保留所属学期的班名及原始版本。具体交互及验收见 [修复规格](../specs/desktop-teacher-feedback-repair.md#管理端登录教师发码和桌面升班)。

## 后续联调使用 MySQL 8.4

2026-11-08 教师确认已购阿里云 RDS MySQL 8.4。前述 PostgreSQL 首段记录保留，新的在线联调以 MySQL 8.4 为目标。前一轮修复审核通过后，第一段核对协作服务的驱动、模型、迁移与事务在 MySQL 8.4 的实际行为，再接续管理员登录和发码验证。重点检查稳定班级身份、唯一约束、版本并发和一次性码的原子兑换。以全新独立测试库实际运行迁移和合成验收为准。在线服务经上海 ECS 与 RDS 的 VPC 私网连接，桌面本地数据仍由 SQLite 管理。[实施顺序与审核门槛](../specs/desktop-teacher-feedback-repair.md#后续实施顺序与审核门槛)

## 已确认的共享周计划范围

2026-11-08 教师确认同班的同周只共享晨谈、集体活动和游戏。其余字段由本班一位老师填写，保存在该老师的本地档案。教师从本人备课选择活动时，搭班老师仅能看到活动名称和日期。任一仍有本班权限的老师均可明确确认最新已保存的共享版本。

联调沿用显式版本、服务端成员权限和本地确认版导出。冲突时保留本次未提交输入并显示服务端版本，教师自行核对、合并后提交。照片、Word 文件和本人备课正文留在本地。
