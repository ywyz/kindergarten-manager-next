# ADR 0006 可选的 Nextcloud 待办同步

2026-11-26，用户选择让工作台与指定的 Nextcloud 待办清单双向同步，并确认同步范围为新增、编辑和完成状态。

## 使用方式与数据范围

教师可以继续只在本机使用个人待办。启用联动时，由教师配置自己的 Nextcloud 账户并选定一个支持任务的清单。桌面通过 HTTPS 和 CalDAV 交换待办标题、截止日期和完成状态。停用后停止网络同步，本地待办仍可打开。删除不向另一端传播。

在「设置 → 姓名与班级 → Nextcloud 待办双向同步」填写服务器的 HTTPS 地址、用户名和应用密码，点击「连接 Nextcloud」。选中要联动的任务清单后，再确认开启。工作台待办区和设置页均提供「立即同步」。更换电脑时，在新电脑上重新连接并选择清单。

## 数据保留与冲突

每条同步关系须绑定账户、清单和任务标识。重试同一笔新增时，应能认出已经写入的任务。两端都发生修改时，保留两份修改并提示冲突，避免用旧内容覆盖后保存的一方。

账户口令按桌面凭据边界保存。个人待办仅在本机和教师所选的 Nextcloud 之间传输。阿里云协作库继续负责园所和同班共享业务。个人档案的备份及恢复流程见 [WebDAV 与在线反馈规格](../specs/desktop-webdav-and-online-feedback.md)。
