## 通用检查标准

- 栏目：日计划所有既定栏目及活动主题、周计划全部栏目与表头存在；园所及人员信息对应管理员配置，日计划教师为创建者，周计划为班级教师名单及保育员；没有遗留样例人名、样例正文或未替换占位符。
- 内容：与所选版本及映射逐项一致；中文、编号、换行、目标和指导完整；缺项与假期区别保留，不编造填充值。
- 分页：每份计划从新页开始，份内长内容自然展开，不因分隔产生额外空白页；当前目标环境无截断、遮挡、表格越界、缺字；标题与所属计划不混淆，跨页内容连续。字体或页数差异可记录，但不能影响上述标准。
- 合并：数量、范围及版本准确，日计划按日期升序、周计划按周起始日升序，周计划按身份去重；单份与合并内容相同，日期边界不串联；不为凑页数缩小内容或省略栏目。
- 标红：仅日计划活动过程使用指定原始拆分基准；含教师最终修改。有基准按已确认差异规则，无基准不标红并提示无法比较；颜色在当前目标环境中可辨认。
- 打开：目标软件无需修复提示即可打开，全部页面可读。单一 LibreOffice 渲染结果不能代替 Microsoft Word 兼容性结论，反之亦然。
