## 导航与编辑方式

1. 样稿顶部用于切换“模块”和“页面”的下拉菜单，实施时改成有文字标签的按钮。应用模块入口沿用现有导航层级；模块内页面通过按钮切换，选中状态清楚。按钮过多时合理分组、换行，不依靠导航下拉菜单隐藏页面。
2. 左侧目录版使用左侧栏目按钮和右侧正文阅读区；概览卡片版按栏目显示摘要及编辑按钮；表格预览版显示业务内容表格或现有记录列表，并在对应栏目提供编辑按钮。月份日历、照片、版本状态等继续使用适合其内容的现有展示，不强行转换为可编辑文字表格。
3. 正文默认作为可阅读内容显示。点击“编辑本栏”等明确按钮打开弹窗，集中编辑对应栏目；原始教案、长文本、生成指导、实际实施材料等也保留可发现的按钮入口，不再把大量输入框同时摊开。
4. 弹窗内使用独立编辑副本：确定或“填回草稿”后回到对应记录的草稿，取消保持打开前的草稿。各模块原有保存、采用和确认语义继续有效，不能把关闭弹窗等同于保存业务版本。已有专门配置保存／恢复确认弹窗沿用其实际操作语义。
5. 日期、年级、学期、场地、供应商等**数据选择控件**不在“导航下拉改按钮”的一刀切范围内；根据字段继续使用适合的控件。真实密钥保留现有安全配置流程，不放进通用正文弹窗或日志。
6. 各生成按钮应醒目、文字直接，使用现有主题的主操作样式与足够的点击区域；等待、禁用、失败及可恢复状态清楚。减少输入框不等于藏起生成、保存、比较、导出等常用入口。
7. 弹窗绑定其打开时的模块、记录、版本／编辑会话与栏目。切页、切记录、迟到的异步响应不能把旧弹窗内容填到新页面。保持键盘操作、长文本换行、明暗主题和关闭后的焦点返回；窄窗口内容及按钮不重叠、裁切或不可达。

本轮修改界面组织方式和直接相关的交互，不借机新增业务流程、数据库迁移、供应商、自动 AI 调用、依赖升级或系统架构变更。沿用 Vue3／TypeScript／Element Plus 和现有桌面宿主。

## 必须保留的内容与行为

- 日计划：原始教案完整保留；新拆分的六字段保真；拆分采用并保存成功后只按候选目标年级和刚保存版本自动接续一次适龄；适龄结果仍比较采用，普通保存／旧计划／历史恢复不补发。单一任务面板及未决回执处理保持。
- 日计划其他活动：成功填草稿、教师保存；任务使用冻结的实际场地配置。晨间双游戏名称和唯一名称重点保留，仅重点组展示目标与指导；室内和现有下午户外各两个实际区域和一个名称重点，配置不足不虚构，不重写历史人工内容。
- 日计划反思：真实实施材料要求、受理后的实时思考与进度、成功一次直接回填草稿且不隐式保存，全部保持。新输入、材料、版本或页面变化时不得覆盖；失败和未知提交不自动重发。
- Word：只导出已保存版本；缺项提示与确认、拆分基准比较标红、晨间单组详情及反思与支持策略格式一致性保持。界面布局不能改变历史版本、导出映射及周计划来源。
- 周计划：主题、每日活动及来源、本周栏目和材料、刷新／核对来源、共享周和确认版本保留。三项户外游戏分别具有名称、共同目标、指导要点、重点指导；另外的单一重点区域保留环境类型、区域、游戏名称、目标、指导与支持。三个 AI 操作分别发起。
- 游戏观察：观察资料、对象与环境、目标、记录、健康／语言／社会／科学／艺术五领域分析、支持策略、有序照片、历史和导出均保留。
- 一对一倾听：五领域、观察目标、图片组及每组倾听记录、星级、综合评价、支持策略、照片选择／顺序／旋转与合册保持。
- 课程审议：原稿全文、活动资料、目标／准备的原稿与调整、过程／理由、二次稿、归属确认和局部修改、候选采用与导出保持。
- 工作台、设置、在线协作、首次设置、备份恢复与更新：全部现有入口及必要确认保持；不因样稿示意而变更资料权威、联网行为、凭据处理、恢复替换、共享确认或更新安装流程。

各模块原有 AI 候选比较／采用规则继续按各自 Contract 执行，不能把日计划反思的直接回填规则扩散至其他模块。手工编辑、保存失败、冲突、未知回执、页面离开及关窗保护同样保留。

## 验收范围

按模块检查按钮导航、阅读区、编辑弹窗确定／取消、保存与返回、长文本、窗口缩放和明暗主题。通过真实组件验证数据与任务状态，不仅断言模板文本存在。特别覆盖打开弹窗后切页／切记录、生成期间新输入、重复点击、迟到响应、保存失败和恢复；不得破坏前轮自动适龄及反思保护，并执行受影响回归。

执行与改动范围相符的前端类型检查、模块／公共组件回归、独立 D1 源码构建；如果确有后端或导出改动，再执行对应回归。源码 UI 使用合成数据或原已授权隔离环境检查，不自动调用教师的真实供应商。已有输入法和休眠结论按项目边界保留，不扩大穷举测试。

交付必须是完整模块清单均完成并经 Codex 独立审核；实现者自测不能替代审核。问题交回对应实现者修复，再复核受影响范围。结果记录应区分自动检查、源码 UI、Word、真实 AI 与教师体验，未验如实列明。
