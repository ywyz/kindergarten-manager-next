状态更新：2026-10-07。本文为 1C 的有效工程规格，1C 已实现并完成阶段审阅，1A／1B／1C 已部署。实际部署见 [部署结果](../bootstrap/ai-slice1abc-deployment-result-2026-10-05.md)；产品结论见 [Windows 验收报告](../bootstrap/ai-slice1c-desktop-validation-2026-10-05.md)，相关夹具子例仍受阻，尚未全通过。业务代码由 OpenCode 唯一写入，本文不自动授权重做或部署。

依据：[1B API 定稿](ai-settings-api-1b.md)、AI Service／提示词规格、[1B 审阅](../bootstrap/ai-slice1b-closeout-review-2026-10-04.md)。1C 只有设置界面，不实现调用供应商、测试连接、worker、AI 生成按钮、候选、材料或完整 W6。

## 1. 入口与文件范围

复用现有 `SettingsView.vue`：教师、待分配教师和管理员均有本人 AI 配置及个人指导入口，不以 class_id/can_prepare 限制设置。管理员另有独立“系统默认指导”面板，明确与管理员本人的指导分开，教师不显示默认编辑入口。沿用现有 App.vue 的设置页导航，不新增 Vue Router／状态库／网络依赖。

允许 `frontend/src/api.ts` 增加 12 条调用、`types.ts` 独立 1B DTO 区域、`SettingsView.vue` 接入、必要的本片新组件／composable／纯状态辅助文件；App.vue 只作设置导航必要衔接。现有账号和密码功能保持可用。不得写 backend、依赖锁、日／周／Word 页面；如果 API 缺能力先报告，不能靠前端猜状态或扩大接口。

## 2. 本人 AI 配置

- GET 后显示地址、模型、固定协议说明、是否已存密钥、版本及就绪原因。`ready` 文案为“本地配置可用”，并说明尚未验证供应商连接；不写“连接成功”。DECRYPT_UNAVAILABLE 显示当前加密配置不可用，不妨碍其他设置或手工备课。
- 密钥输入独立于已保存状态：空白输入表示不更换、请求中省略 secret；不能把 `********` 填入输入并保存。首次无配置保存须填新密钥；曾清除后可只保存元信息。新密钥非空字符串原样发送，不 trim、不发送 null／空串。PATCH 每次完整提交 protocol_id/base_url/model 与页面保存基线 expected_version。
- 明确“清除已保存密钥”动作，用户确认后 DELETE JSON `{expected_version}`；无 head 的 version=0 处理沿用 1B。清除不等同删除地址／模型，不能用清空输入模拟清除。
- 成功以本次响应更新保存基线，清空密钥输入；失败保留在当前页面内的输入供用户处理。卸载、退出／401、账号切换清空密钥；不写 localStorage/sessionStorage/URL、日志、错误提示、截图或报告。口令输入使用 password，遵循现有安全控件习惯。
- 409 保存本地输入，另取最新服务端脱敏配置展示比较；刷新不能覆盖 dirty 输入或自动推进其提交基线。提供显式“载入最新配置”或“保留输入，以最新版本重新保存”，后者还须用户点击保存，不自动重发。503 保留输入且允许重试／清除，不把缺主密钥归因成供应商故障。

## 3. 全部任务个人指导

列表以服务端 items 为准，覆盖七项：教案拆分、过程适龄调整、日其他活动、周游戏、周栏目、周主题建议、周材料。中文任务名称可映射，实际字段集合必须用 API 返回数据，不能把 v1 字段写死或在客户端改名／删字段／编辑系统协议。

打开详情 GET 只读：未初始化展示最新默认，显式“建立我的指导”才 POST initialize `{}`，不在 mounted／GET 后自动初始化。成功之后 GET 刷新派生状态，幂等结果也不能推断已适配。

初始化后，普通编辑字段来自 `based_guidance_fields`，编辑内容为本人 `guidance_map`；最新默认独立展示。每字段最多 8000 字符，允许空串／换行，保留原文字、不 trim、不解释 HTML。PATCH 只发有变化的字段与编辑基线 personal_revision，空 patch 不提交。正常更新响应直接更新该次已保存基线；后续状态 GET 不能覆盖正在编辑的 dirty 文字。

展示 personal_revision、based/latest contract、最新 default revision，以及普通更新／待适配两个独立状态。初始化不能与“本地配置可用”合并成一个假就绪标签。

普通默认更新：比较本人当前文字和最新默认，各字段选择后显示将覆盖的字段；接受列表非空且无重复，提交捕获的 personal_revision 和 target_default_revision。未选字段保持原值。若尚有未保存编辑，应先保存或显式放弃，再接受／拒绝，避免覆盖本地文字。拒绝为“保留当前指导”，不改个人文字或 revision；拒绝后仍允许主动打开比较并接受同默认，不强制重复弹窗。

2026-10-07 用户确认方案 A：接受绑定教师实际查看并勾选的默认修订；比较期间管理员仅发布更新的默认文字，不使同契约的旧目标失效，也不自动替换教师所见内容。目标仍须存在且与本人 based／当前 contract 兼容，个人 expected 仍须有效。成功只记录所接受修订，更晚默认仍作为未处理更新展示，不视为一并接受。 前端不得静默更换比较目标或勾选字段。

待适配：旧 based 字段仍能普通保存，但禁止接受／拒绝默认。另设完整适配编辑面：按最新 `guidance_fields` 组装，保留同名原文字，新增字段预填最新默认，移除字段原文另行只读展示；只发送完整最新集合。显式“完成适配”携带编辑时 target_contract_version 与 expected_personal_revision；关闭／普通保存不能标已适配。当前 API 不提供详细类型差异，页面只能呈现两套字段、增删、原文和版本，不能虚构类型变化详情或新增 schema 接口。

## 4. 管理员系统默认指导

独立面板按七任务选择，用管理员 GET 的 `guidance_fields/guidance_map/default_revision/contract_version` 展示当前默认。只编辑指导文字，不提供改字段／协议结构入口。PATCH 非空局部 map 与编辑基线 expected_default_revision；成功展示本次 revision，不自动刷新或覆盖管理员本人的指导。冲突保留输入并呈现最新默认，用户决定载入或再次明确提交。

## 5. 请求状态、权限及冲突

复用现有 request()／cookie／401 处理。DELETE 和 initialize 必须显式 JSON body；浏览器自动发送同源 Origin，不能尝试自行设置伪造 Origin。所有版本值来自相应 API，不能借用 accounts.version、日期或本地计数器。

所有配置／任务详情／比较／适配／默认读写都有 loading、失败反馈和重试；重复点击写按钮锁住。task／面板切换及退出使过期请求失效：旧成功、错误、finally 均不得更新新任务的内容／消息／loading；卸载后不回写，账号切换不能复用上一个账号的内存草稿。

每份草稿区分保存基线、本地输入、最新服务端比较数据。409 不覆盖输入、不静默 rebase 或重发；用户查看后才能明确选择新基线。PROMPT_CONTRACT_CHANGED／PROMPT_DEFAULT_CONTRACT_MISMATCH 应提示刷新比较／适配目标，不能重发旧 target；PROMPT_ADAPTATION_REQUIRED 提示进入适配；PROMPT_NOT_INITIALIZED 提供显式初始化；422 为固定通用提示，不期待 fields；403／503 按既有安全错误码显示，不展示原始异常／请求。

切换任务、退出编辑或返回时，若存在 dirty 文字可保留本页内存草稿，或明确确认放弃；不得无提示丢失。不要为恢复草稿增加浏览器持久存储。保存成功后的状态刷新失败，仍记录写响应已经保存，不提示用户盲目重复提交。

## 7. 桌面接续的准备与授权

1. OpenCode 先完成 1B 补修并经复审，再完成 1C 编码／自动检查／报告；协调者复核后形成实际可部署文件清单。
2. 部署到既定远程独立验收实例须单独授权，明确新迁移、低权限账号和 AI 主密钥准备；凭证通过安全渠道提供，不写文档，不借用旧系统私钥。当前 I5 实例存在不代表已经运行 AI 1A／1B／1C。
3. 桌面验收交接填写实际 HTTPS URL、部署版本／工作区来源、迁移 current、测试账号角色及合成夹具。只有验收环境托管者获授权后才发布 v2／切换服务主密钥；桌面执行者不能自行修改共享库／服务器。不能用本机 WSL API 代替远程实例。
4. 桌面版按 C1–C7 在真实浏览器操作，记录 OS／浏览器版本、案例步骤／结果／时间和去敏截图；不截图输入密钥、Network 请求载荷或凭证。不能用 mock 页面通过证明真实持久化。
5. 桌面输出 `docs/bootstrap/ai-slice1c-desktop-validation-<实际日期>.md`，分列真实通过／失败／受阻／未执行，以及 1B 自动证据所覆盖但尚未产品验收的子例。未取得 v2 或主密钥夹具就明确保留该子例，不宣布全通过。

设置验收本身不需要付费调用。Office／WPS 逐页材料与完整 W6仍属于后续材料切片，不添加到这次设置验收完成门槛。
