## 2. 建议的教师流程

1. 本地应用就绪后后台检查一次新版，保留手动“检查更新”入口；检查不阻塞打开日计划、保存和Word导出，不并发重复检查。更新服务不可用时可继续工作。
2. 有新版时展示当前／目标应用版本和更新说明，提供下载及稍后处理。启动检查只提示，下载由教师发起，不自动安装或强制退出。
3. 在应用内显示下载进度和失败状态，支持取消及明确重试。下载到独立暂存位置，完整校验后才能进入可安装状态；不把下载开始或结束直接显示成更新成功。
4. 教师选择安装并确认后，沿用现有退出握手：收口IME、保存正文、处理设置／候选草稿及在途AI任务；保存失败、结果不明或退出未获许可时保持原页和输入。更新不能绕过既有保护，也不能擅自改写AI任务状态或重发请求。
5. 旧窗口、后台服务、执行进程与数据库句柄确认退出后，才切换完整程序包并启动新版；继续使用原本机数据根和凭据根。新版实际启动就绪并核对版本后，才记为安装完成。
6. 下载失败、校验失败、安装被阻止或新版未能就绪分别提示，并保留旧程序、升级前备份和必要恢复信息。未知结果先核对，不重复发起并行安装。

应用版本、构建身份、数据库migration revision、日计划内容版本分别管理，不能把当前计划v6当作应用版本。

## 3. 工程边界

### 3.1 完整程序包与可信来源

当前基线为PyInstaller完整目录包；更新对象须包含其前端、Python运行资源、迁移和模板，不能只替换EXE。优先沿用现有技术栈和桌面宿主职责，不默认新增安装框架、常驻服务、数据库或全局管理员权限。

发行源、版本元数据、包身份与来源认证方式尚未定案。U1开工先提出具体工程方案：固定受信任的来源、平台／架构和版本识别、完整包大小及摘要、重定向限制、元数据和包不一致时的拒绝规则。不能把包内自带SHA清单当作发行来源证明，不能把任意远端URL交给宿主任意下载或执行。真实下载源和正式发布安排另行落实；合成受控服务不冒充真实发行渠道。

同一应用内的进程交接和文件切换先在现有桌面边界内设计，避免前端直接执行系统命令。若确实需要改变一级技术栈、既有模块边界或通信机制，先交Codex形成ADR草案，未经确认不实施该变更。不得为了实现更新顺带改变ARCHITECTURE.md。

### 3.2 数据与安装失败保护

- 程序目录、下载暂存与用户数据分离；保留教师档案、配置、日计划全部版本／基准来源／恢复回执、AI候选及任务记录，不覆盖或重新初始化真实数据根。
- 复用现有数据根独占运行锁、占用检查及冷升级；不杀旧进程，不在应用仍运行时替换其程序文件。
- 需要迁移时沿用SQLite一致性backup及完整性／外键／revision检查，包含已提交WAL内容；备份失败不迁移。未知或更新格式继续拒绝旧版写入，不stamp或自动downgrade。
- 程序文件回退与数据库恢复分开判断。若数据库已经升级，不能无条件退回旧程序，更不能自动覆盖用户数据库；失败报告说明实际阶段并保留现场。
- 包解包／切换限定在受管路径，拒绝越界路径及链接绕过；下载不完整、空间不足、目标被占用或切换中断时，不能让半个程序包被当作有效安装。
- 复用现有同机凭据存储，不复制真实密钥、不设计跨机凭据迁移。更新和重启不自动重放已发送或结果不明的AI请求。

这里的本机升级备份属于现有数据保护要求；不据此启动WebDAV、一致性快照上传、换机接续或两端冲突协议。

## 5. 必要验证

1. 无新版／有新版／网络不可用／超时／错误元数据；启动检查与手动检查去重，手工工作不受阻。
2. 完整包身份／平台不符、摘要或大小不符、下载中断、越界解包和暂存被占用；原程序与数据保持，失败不进入安装。

4. 旧进程未退出、切换中断、新版启动失败、迁移失败、未知／更新revision；核对实际阶段与完整文件，不能以“命令已发出”当作成功。
5. 独立合成旧数据升级后，档案、配置、全部历史及来源／回执逐字段保留；同机合成凭据可用，旧AI请求不重发，Word仍读取正确已保存内容。

仅使用独立无真实凭据数据根、受控下载服务及明确的测试程序目录。现有Python3.14.7／Windows x64／标准GIL和业务依赖保持；先列文件与验证范围，失败停止对应链并保留首次现场，不反复全跑无关套件。

## 8. 2026-10-24开工方案核定（限定源码／合成工程）

原OpenCode方案见[实现记录](../bootstrap/desktop-update-result.md)。Codex核定下列工程约束，按U1审核后接续U2／U3；不改变一级技术栈、业务模块边界或数据权威，不修改ARCHITECTURE.md：

- 更新管理器与独立小更新器均属于现有桌面宿主维护职责；后者只等待旧进程、校验并切换完整包、启动新版及核对结果，不新增常驻服务、业务API或安装框架。使用现有Python／PyInstaller；本轮只实现构建支持，不实际构建运行新冻结包。
- 采用固定HTTPS源与嵌入Ed25519公钥验证签名元数据，复用现有cryptography；签名绑定版本、完整包摘要／大小、平台和构建身份。Windows Authenticode、证书采购和SAC相关签名继续暂停。合成验证允许在独立临时根生成测试TLS证书及测试发行密钥，不能使用或创建正式发行私钥。
- **真实发行URL／公钥及发布流程未选定。** 本轮核定可审阅的发行构建配置契约：单一固定HTTPS源／路径、内嵌信任表，运行页面／环境／CLI不可改；缺少有效配置时明确渠道尚未配置并继续手工使用，不联网猜测或回退任意地址。合成受控TLS源仅由测试构造注入，不进入产品入口。不部署服务、不创建Release、不上传包；工程通过不等于在线发行已可用。此为本片明确未验边界，不伪造真实URL或信任身份。
- 稳定应用ID为`kindergarten-manager-next`，渠道`stable`，当前源码基线版本`0.1.0`；严格数值三段SemVer，先不引入预发布渠道。构建ID使用UUID，版本和数据库revision独立。安装布局可采用当前用户`LocalAppData/Programs/KindergartenManager/app`及相邻稳定更新器，首次安装／快捷方式另行待验；源运行默认禁用产品更新，不能将仓库或旧验证包目录当正式安装目标。
- 安装计划必须绑定旧进程的真实身份与创建时间／持有句柄，防PID复用；同时取得独立安装锁，未知结果先核对，不重复并行安装。旧进程、服务、AI进程及数据根锁／数据库句柄释放后才切换，旧进程超时不强杀。优先复用当前已信任的更新器，不能让页面选择执行目标。
- 新版就绪回执绑定本次plan、随机nonce、目标版本／build及实际新进程身份，拒绝旧回执／重复回执；须在本地运行时与迁移检查完成、服务和真实页面握手就绪后确认，不能在Popen或只写文件后宣布成功。重启仍显式使用原数据根和凭据根，更新器不读取密钥。
- 下载、ZIP和清单校验还须拒绝Windows ADS、设备名、尾点／尾空格、路径大小写冲突、链接／重解析／硬链接绕过；实际暂存和程序路径必须分离于数据／凭据并同卷，拒绝越界或覆盖现有旧包。
- 取消可清除本次未完成下载；故障材料／未知安装状态不自动清理，首次失败独立保留。不能用泛化启动清理删除失败现场。包切换前后写可核对的阶段记录；数据库状态不明或可能已升级时禁止自动程序回退，更不能自动恢复数据库。真实新进程尚未证实退出也不能切回目录。
- 桥接沿用现有受限端点与page_ready／同源防护，页面不传URL、路径、PID、命令或摘要；安装意图绑定既有close代次，取消／超时／保存失败等只清除自己的意图，普通关窗不能遗留安装意图。下载与安装不能干扰原有正文、IME、草稿和AI保护。
- 小更新器即使已经启动，也不能仅凭“旧PID后来退出”安装旧计划：窗口销毁失败、关闭被撤销或代次失效时，必须撤销对应安装授权；后来一次普通关窗不能使失效计划重新生效。目录切换前重新核对授权、实际完整包字节与文件清单及占用状态，受管暂存不能被当作永久可信输入。

## 9. 2026-10-25工程收口契约与后续边界

- 产品helper只使用固定受管布局、固定已认证主入口和自身发行配置，不能把持久化plan内的命令或公钥配置当产品权威。专用源码验证参数在Runtime创建前校验并拒绝冻结入口；就绪测试上下文须同时满足已校验非冻结源码相位及显式身份，不能只凭环境变量启用，产品helper清除继承变量。
- 授权在获取后、旧进程退出后及切换前核对同一plan／nonce／close代次；无法确认进程身份、缺exe或同PID／创建时间但exe不符，均不能当成退出。新回执绑定实际当前身份、原数据／凭据根、真实服务、page_ready和新进程；Popen或写文件不等于就绪。
- 安装单一性包含pending／bound／authorized、helper存活及未知结果，并在重启后恢复持久化未决状态。状态查询／安装前须重新核对，正常完成后同实例可恢复；终态严格关联自身plan／nonce及有效receipt，历史success按自身目标核对，不要求当前应用永远等于旧版本。损坏／阶段不能判明时保持unknown，不据记录读取失败推定未启动。
- 阶段记录按跨进程安全方式保留，不静默清空坏记录。任何未知状态不自动恢复数据库、不盲目回退程序或重放请求；首次失败保留，新根验证通过不改写旧根未修事实。
- 当前实际head为`20261023_0005_local_history`。合成应用0.1.0→0.2.0在同schema完整重启，另用真实0004→0005验证冷升级；不虚构0006，不将合成0.2.0当正式发布版本。网络中止的私有socket路径仅限定CPython3.14.7／当前Windows验证，未来运行时变更需复核。
- 本轮U3使用合成形状目录包、当前仓库源码与独立前端构建；没有执行冻结载荷。真实发行URL／正式公钥、冻结包安装／资源、首次安装／快捷方式、4551及教师逐页Word仍未验。活动AI“停止等待并退出”UI分支未由本轮新增验证，既有D2范围保持。真实库、凭据、旧包、Word及首次失败材料全部保留，不读取真实密钥、不调用真实AI／WebDAV、不签名或发布。
- 下一步仅准备游戏观察记录规格与待确认问题供用户审核，字段／图片／AI／导出不从旧v1推断；不自动派发游戏实现，跨设备继续后置。
