## 验收内容

保留 [Word 模板验证计划](word-template-validation.md) W1–W6 的内容、分页、表格、动态列、标红、范围、版本与合并标准，以及 [Word 导出实施规格](word-export-implementation.md) 的权限、缺项确认、份数上限和审计边界。日计划最多实际入选 31 份，周计划最多实际入选 8 份；32／9 份才超限，日期跨度不是超限依据。

真实浏览器下载须核对中文文件名、非空字节、SHA-256、DOCX ZIP 完整性和无匹配／失败不产生文件。用实际下载文件在选定 Word 或 WPS 文字中逐页查看页面视图／打印预览；无修复或转换异常，无裁字、遮挡、表格越界、缺字或分隔引入的空白页，内容与所选版本一致。Protected View 单列记录。检查后关闭且不保存改写，再复核文件哈希。

必须复核本轮范围竞态：日／周范围 A 请求被延迟，改为 B 后释放 A，旧 200 不下载、不关闭 B；日计划旧 409 不覆盖 B 的 facts／expected_context；旧错误不覆盖 B，旧 finally 不清除 B 的 loading。模拟延迟仅证明前端行为，不能代替真实服务下载和桌面版式。

## 证据与边界

实现、静态审阅、自动测试、远程部署、Trae Work 浏览器、下载落盘、Office／WPS 逐页版式分层记录“未执行／通过／失败／受阻”。某层通过不替代其他层；缺少桌面证据时仍为待验收，不要求重新安装 WSL。

验收服务器使用独立目录、内部 API 端口、数据库及低权限应用账号，前端构建产物由现有 Caddy 提供 HTTPS 与 API 代理。本轮部署是 I5 验收实例，使用合成夹具；不导入旧业务数据。AI、提示词与持久任务尚未实现，容量、备份恢复和正式上线验收仍另列。

用户本轮已授权连接、部署、修复、commit 与 push，并明确允许协调者直接做两处导出竞态最小修复；该例外不改变后续默认业务代码由 OpenCode 写入的约束。
