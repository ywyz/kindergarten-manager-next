- 六份表格成品的照片均在“观察记录”栏内，数量为2或3张；有先图后文、文中插图、图文并排等不同布局，不能推定必须3张或固定排列。

- “儿童数目”与“幼儿姓名”数量存在不同，用户进一步确认C20：前者为游戏参与总人数，后者为重点观察对象，可为子集；不自动绑定。成人数目也由教师提供，不能从照片人数自动推算。
- 模板评价分析预列健康、语言、社会、科学、艺术五项；足球成品允许写某领域表现不明显，用户已进一步明确固定五项、证据不足如实说明（C9）。

## 2. 范围与教师完整流程

| 幼儿年龄 | 本份一个统一观察年龄，如5岁，同龄合写 | 可空 | 必填；不逐人要求年龄，不由年级／照片推算 | 一个年龄栏合写，不求平均 |
| 观察环境 | 教师填，可为简短区域名 | 可空 | 必填，不要求完整环境叙述 | 列缺项，确认可留空 |
| 观察目标 | AI或教师撰写的关注点；不另设观察目的栏 | 可空 | 不要求预写；意图可在简短说明中选填 | 当前正文，可留空 |
| 观察记录 | 过程正文及本份照片；多人可同文描述共同情境和个人表现 | 可空 | 不要求预写过程 | 正文在前、照片在后 |
| 评价分析 | 健康、语言、社会、科学、艺术五项 | 可未完成 | 固定五领域，证据不足如实说明 | 保留五领域结构；空项列缺项 |

草稿可不完整，不因AI未成功而拒绝保存。AI最少必填只用于AI操作，不套作手工保存或导出门槛。缺项与错误分别处理：可空不等于接受错误日期、负数、损坏图片或姓名错配；具体字段语法、反馈与缺项判定由E01核定，不擅自增加新的必填步骤。

### 3.2 人数和统一年龄

儿童数目包含重点观察对象，不是班级在册数或照片可见数。例如5人参加游戏、重点观察1人，儿童数目为5，幼儿姓名只列该人。成人数目独立填写，不默认1，不等于应用账号数。不从目标人数反填已知总人数。

本份统一年龄供所有目标幼儿使用；不建立出生日期／逐人异龄／名册。多人同龄不等于表现相同，AI仍按材料区分个人表现。已填儿童数目少于目标人数时应指出矛盾，不偷偷改数或删姓名；具体校验与草稿保护由E01核定。

## 5. 完整行为规则

### 5.1 生成与单栏重写

教师明确触发一次四栏生成；一次操作不预定实际API拆分次数，工程方案须说明实际请求组织。单栏重写只生成该栏候选，其他栏／人工修改保持，可参考同份其他当前正文维持一致，不顺带改写其他栏。

输入包括教师资料、统一年龄、照片顺序／可选说明及已有正文，教师文字可为空。允许AI补写对话和基于情境的动作衔接；教师已给的原话、时间、人物对应优先。具体分钟、持续时长由教师给出，不增加未提供的完整新事件，不声称从静态照片听到了原话。

多人无法对应姓名时，先写材料能确定的共同情境并提示补充；不将未确认动作指名给某人，不强迫教师逐图标注后才生成。评价固定五领域，没有证据就如实说明，不能用刚补写的对话循环证明发展结论，也不为凑五项虚构表现。

任务绑定实际发送的资料／图像／说明／正文版本；执行中允许正常编辑，晚到结果不自动采用。配置、提示词或记录变化不自动重生成。请求未知结果不自动重发，恢复历史、重开程序或导出失败都不重放AI。

### 5.2 候选、采用与人工编辑

候选与当前正文分开。支持整份采用、按栏采用，评价分析作为一个完整栏目含五领域；单栏重写只替换目标候选。采用后仍可手改，不增加采用后再审批／定稿的必经步骤；手工正文不要求先有AI候选。

采用只更新明确选中的正文，不能因晚到响应、重写成功或读取详情而覆盖新编辑。整份采用须一次完成四栏写入，失败不留下半份；按栏采用保持其他栏。过期输入候选如何提示、重新核对与采用的具体协议见E07，不能默许过期候选静默生效。

未采用候选、实时思考、审核提示不进入Word正文。候选保留／重开与旧候选展示由E07核定；已成功生成候选不得因普通页面切换被静默当作已采用或诱发重试扣费。不能照搬旧页面的阻塞草稿逻辑，强迫先采用候选才能离开；与C14的保存离开规则如何衔接须明确审阅。

### 5.3 草稿、保存与离开

自动保存草稿，同时保留手动保存；允许正文或资料未完整、无照片、无AI结果。保存至少覆盖类型、基本资料、统一年龄、姓名、四栏正文、照片集合／顺序与说明。候选单独保存或引用，不能混成当前正文。

清楚显示未保存／保存中／已保存／失败；失败保留编辑和材料，允许重试。离开、切记录／学期、进入设置和关窗先保存当前编辑成功，失败留页；保存成功后又有新输入，也不能以旧成功放行。输入法结束输入、重复动作、未知保存结果、原生对话框与关窗在途AI处理见E05、E09。

选图后保存应用管理的材料，不能只存外部原路径；未完成／失败导入不得宣称图片已保存。断电、崩溃只能保证成功提交的部分，不提前承诺零丢失。图片故障不得清空其他草稿，处置由E03核定。

### 5.4 单份、合并与本机文件交付

导出前先完成本次编辑保存，失败不交付旧版冒充当前版；这是观察记录规则，不改变日计划导出行为。单份或勾选具体多份，可混合三类型；不自动把范围内全部记录加入。

默认日期、起始时间升序；缺日期置末，同日缺起始时间置当日末，同值按创建先后；始终显示实际清单，可手动调整。每份从新页开始，份内自然分页，不强制两页，不继承日计划31份／周计划8份的业务限额。

每份使用自己的资料、类型、正文与照片，读取明确的成功保存版本。缺项确认绑定本次选集、顺序、版本、照片和缺项事实；变化后须重新核对，不能一份文件混入不同时间内容。物化导出材料后再生成、另存为，不带数据库事务等候文件对话框。

单份默认“日期＋类型观察记录＋重点幼儿姓名.docx”；合并默认“游戏观察记录＋日期范围＋份数.docx”，另存为可改。未填日期用“未填日期”，不伪造今天；部分日期缺失、多份同日、长姓名及非法文件字符等具体呈现由E11核定，不删改正文资料。

区分生成失败、另存为取消、保存失败和实际成功；无选中记录不生成空文件，失败不交付少页／少图文件，重试不调用AI。取消不清空记录，不静默覆盖已有文件。Word为时点副本，后续修改／历史恢复需要重新导出。

### 5.5 AI补写提示

提示只在候选审核区：总体提示对话等细节含AI补写，可展开相应片段，不要求逐条确认。片段必须对应当前候选；重写后不能沿用旧文字定位。无法可靠定位时仍保留总体提示并说明，不能伪造精确标记。

补写标记辅助核对，不是真实性认证，未被标记也不能自动视为现场实录。整份／按栏采用不把标签、颜色、脚注或审核说明拼入正文，单份／合并Word均不带标记；教师自己写入正文的文字保持原样，不借自动清理删改。

### 5.6 Word表格、字号与照片

三类型沿用户模板A4纵向、原六列网格与8行业务表格及栏目顺序，标题为园所名称＋游戏观察记录＋类型；不额外加入学期、独立故事标题或封面目录。园所空时留空其部分，不使用样例占位。

标题宋体16磅加粗居中，基本资料11磅、四栏正文12磅；观察环境等模板固定栏目与其他细部映射由E11明确，不能随意改四栏字号。标题长时自然换行居中，表格可增高跨页，不能固定高度截字；不继承日计划标红规则。

观察记录先正文后照片，按材料顺序从左至右、从上至下，每行最多两张，单张居中，等比不裁切。横竖图可因版面单张成行，不为凑两图压扁或缩得难辨；单图不被分页切开，空间不足移下一页，不盖字、不压图，不混入下一份记录。

简短说明默认不印，不自动转成图注或第五栏；教师可把需要交付的文字写进正文。按当前记录已保存的照片集合／顺序输出，不自动删重／挑图；不预加单次选图或打印说明开关。原图、AI工作图、导出图的清晰度／保留关系由E03核定，坏图不能用空白占位掩盖。

### 5.7 缺项、无图、空记录与坏图

| 情况 | 规则 |
| --- | --- |
| 表头／正文缺项 | 按记录列清具体字段；教师可确认保留空栏导出，不自动补写、不悄悄跳过整份 |
| 五领域缺项 | 保留五领域结构；明确写证据不足属于有效说明，不作为缺项再次催写；只有固定标题不算实际正文 |
| 无照片、有正文 | 可手写、保存和导出；其他缺项仍列清确认，不要求先调用AI |
| 无正文、有有效照片 | 不算空记录；四栏缺项仍列清确认，可保留空栏导出 |
| 只有表头／空白正文且无有效照片 | 算空记录，先补写／加图或明确从本次选集中移除，不直接导出 |
| 只有未采用候选 | 候选不计入当前正文；不能为了非空偷偷采用。若无有效照片／正文，仍按空记录处理 |
| 已添加图片损坏／缺失 | 指出记录与具体图片，先修复或由教师明确移除并保存；不能静默漏图、换图、当作无图或输出空白占位 |
| 多份中的空记录／坏图 | 不静默跳过，本次集合先解决问题；教师可修复或明确取消该份勾选后重新核对 |
| 多份普通缺项 | 集中列清并确认本次集合，不逐份重复弹窗；缺项确认不能绕过空记录／坏图处理 |

固定栏目标签、空格及自动生成的五领域空骨架不算实际正文；已填正文如何正规化见E01。导出期间失败不影响已保存记录，返回编辑／取消选择不删除业务记录。

### 5.8 资料带入与历史表头

带入只在新建取创建当时当前资料。回补旧日期不虚构历史班级／教师，教师可改本份。重开、升班、改档案不覆盖旧记录的园所、班级、观察者和统一年龄。

本份修改显示姓名或班级文字，不切换本地身份、不创建班级／教师账号；档案维护仍通过已有配置入口。本地制作身份与文档观察者称呼、班级内部身份与本份表头文字需在E02明确区分。

### 5.9 同日多份与旧学期查阅

日期不是唯一身份；相同幼儿、类型或时段也可多份，主动新建不覆盖已有记录。单次新建请求重试／双击仍须防止意外重复创建，不能用允许多份取消幂等保护。

旧学期记录可查、改、导出；不受当前上课状态或修改后学期日期范围裁切。浏览学期只改筛选，不迁移原记录；切换前仍先保存。清单须可区分多份记录，具体入口、筛选／分页和跨页选择由E10核定，不增加必填内部标题。

### 5.10 日期、学期与未归属

任意有效观察日期可用，不受日计划上课日／同日唯一限制。新建按日期匹配已有学期，未填或无匹配先存未归属，以后可明确选择已有学期；不自动新建学期或改日历。

未归属记录必须可见、可改、可导出。日期更正跨学期时展示日期与归属供确认，不静默挪动；学期范围变动不批量重算旧记录归属。取消确认、补空日期及恢复历史日期等交互由E04核定，不得因提示未解决而丢当前稿。

### 5.11 历史预览、整份恢复与保留

预览同一版本的基本资料、类型、四栏正文、照片集合／顺序及说明，不能历史文字配当前照片。恢复前先成功保存现稿，再从选定历史建立新版本，保留原历史与刚保存现稿；失败留页，不覆盖历史或回退版本号。

恢复整份资料（包括观察日期和统一年龄）、类型、正文、照片／顺序及说明；记录身份不变，不改档案或班级／学期配置。历史日期与当前归属冲突时须在预览中明确并按C25确认，不能为默认保留归属漏恢复历史资料，也不能自动改配置。

自动保存保护当前稿；手动保存、采用、离开和恢复有实际改动时保留历史节点，重复无变化不制造新历史。判断改动须相对最近保留节点，不能因自动保存已成功就漏掉应保留的节点。具体草稿／不可变版本与展示组织见E05。

历史引用的照片保留，当前移除不等于可从历史永久删除；首期不自动清理历史／照片。缺失历史材料时说明问题，不静默取当前照片代替或生成不完整恢复。恢复不调用AI，不自动采用旧候选，在途结果不能覆盖恢复后的正文；晚到编辑、重复恢复、提交响应丢失按E08验证。

历史是本份本机业务版本，不是Word导入、整库回滚、回收站或WebDAV恢复。单栏历史恢复、版本清理与保留天数未纳入首片。
