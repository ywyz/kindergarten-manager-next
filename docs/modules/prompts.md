# 提示词 Contract

## 职责与数据归属

系统维护各 AI 任务的输入变量、输出字段名称与格式，以及默认生成指导。教师拥有个人字段生成指导，可以修改指导内容，不能删除或重命名字段，也不能改变返回结构。

支持全部首版 AI 任务：教案拆分、活动过程年龄适宜性调整、日计划其他活动生成、周计划游戏选取与补足、其他周计划栏目生成及主题建议。具体拆分为几个实际 API 请求是待定实施细节，不影响能力范围。

## 输入与输出契约

输入为任务类型、教师身份和所需版本；输出为可执行的系统字段契约、实际采用的指导及版本、适配状态。不得向任意教师暴露其他教师的个人指导作为可编辑内容。

字段结构约束属于系统，AI 返回值须由程序校验，不能只在提示词中要求 JSON 就假定符合契约。个人指导不得绕过权限或计划确认流程。

## 更新规则

管理员修改系统模板后，提示教师选择是否接受或覆盖个人指导，不静默覆盖个人内容。普通指导文字更新可拒绝，继续使用个人版本。

必需字段变化时保留个人文字，提示适配；适配完成前暂停对应 AI 操作。手工编辑、保存不受此限制。字段适配状态必须能被 API 和工作进程一致识别。

待执行任务使用最新有效配置与已适配提示词；已开始任务保持启动版本，记录实际使用版本。改变提示词不自动重生成已确认计划。周计划自动任务使用当前负责人的个人指导，接管后切换到接管者。

## 非职责

本模块不执行网络调用，不保存 AI 密钥，不直接修改日计划或周计划，也不替教师确认候选。

字段新增后的适配界面、指导继承展示和历史版本保留期限在实施规格中细化；未获确认不能增加教师任意改写整段协议的能力。
