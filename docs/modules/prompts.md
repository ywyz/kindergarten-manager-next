# 提示词 Contract

Architecture v2 的本地提示词合同依据 [ADR 0004](../adr/0004-local-desktop-architecture-proposal.md)。兼容默认指导的更新按 [提示词功能包规格](../specs/desktop-teacher-feedback-repair.md#6-提示词功能包) 执行。

## 职责与数据归属

应用维护各 AI 任务的输入变量、输出字段名称与格式，以及默认生成指导。使用者拥有个人字段生成指导，可以修改指导内容，不能删除或重命名字段，也不能改变返回结构。

日计划支持教案拆分、活动过程适龄调整与其他活动生成；周游戏、所选栏目及材料的输入与提示词版本见[周 AI 工程合同](../specs/desktop-weekly-ai-engineering.md)。游戏观察两类任务、四栏及固定五领域的运行时校验／执行已通过E06／E07限定工程核查；该观察切片未增加观察指导编辑器。

具体拆分为几个实际 API 请求在调用规格中细化，不凭提示词列表增加调用次数。

## 输入与输出契约

输入为任务类型、本地使用身份和所需版本；输出为可执行的系统字段契约、实际采用的指导及版本、适配状态。个人提示词保存于本地数据，由 WebDAV 快照规则管理跨设备接续；不设同班教师互相查看或编辑个人指导的能力。

字段结构约束属于应用，AI 返回值须由程序校验，不能只在提示词中要求 JSON 就假定符合契约。个人指导不得绕过应用会话校验或计划确认流程。

## 游戏观察提示词扩展（2026-10-26，E13设计核定）

两个观察bundle登记／守卫后幂等补种见[基础核查](../bootstrap/desktop-game-observation-foundation-review.md)；E06／E07运行时输入／输出校验、视觉执行及候选metadata已通过[最新核查](../bootstrap/desktop-game-observation-ai-review.md)。旧daily七包及观察v1 bundle字面schema／hash保持，内部冻结input与实际wire投影分别版本化，不把运行时wire冒称旧登记schema。提示词UI后续边界保持。

应用固定维护game_observation_generate及game_observation_rewrite两类bundle、输入和输出schema；完整生成恰为观察目标／观察记录／评价分析／支持策略四栏，评价固定health/language/social/science/arts；单栏重写只输出目标栏，评价作为含五领域的完整目标。

教师已确认的是照片可选简短说明（可含观察意图），不据此新增观察个人指导输入框或完整提示词编辑器。内部default/personal/contract版本机制保留，日计划原个人指导规则不改。业务input与工作图提交时冻结，claim按最新有效配置／已适配提示词开始，execution钉住实际版本；后来修改不使兼容旧候选误过期，字段不兼容仅暂停对应AI。

允许补写情境对话及动作衔接，不造未提供精确分钟／时长或完整新事件；多人无法对应姓名时写共同情境并提示，不猜姓名动作，不把补写反作已核实评价证据。补写总体提示与定位片段仅供候选审核，定位越界／hash不符降级总体提示，不拼入正文、Word或后续提示词。

精确发送清单、实际上下文hash、候选复核／采用见[观察Contract§6](game-observations.md#6-ai-投影候选与采用)。E06／E07服务层已实现；R12仅强化观察执行协议的姓名对应／审核提示分离，保留C11补写与C32资料缺口说明，不做猜姓名／删句后处理。Codex曾误判换行而提出R13，已全部撤回，未保留格式清洗。原bundle／指导种子及D2更新规则保持，设计依据见[E13记录](../bootstrap/desktop-game-observation-contract-review.md)。

## 更新规则

桌面从受信任的 HTTPS 来源获取默认指导包，校验 Ed25519 签名、SHA-256、客户端兼容范围、任务与字段白名单及修订身份后，整包启用。检查失败时沿用已验证的可用包，首次离线使用内置默认。首批开放九类任务的默认指导文字，四个独立周栏目继续使用固定的内置契约和修订。包格式、手动与后台检查及发布规则见 [提示词功能包规格](../specs/desktop-teacher-feedback-repair.md#6-提示词功能包)。

使用默认指导的任务在下次开始执行时采用最新有效的兼容版本。已有个人指导继续生效，教师可在现有适配入口查看并主动采用新默认。保存个人指导由教师主动操作，AI 执行仍由各业务入口触发。

必需字段变化时保留个人文字，提示适配；适配完成前暂停对应 AI 操作。手工编辑、保存不受此限制。字段适配状态必须能被本机 API 与本地执行组件一致识别。

待执行任务使用最新有效配置与已适配提示词；已开始任务保持启动版本，记录实际使用版本。改变提示词不自动重生成已确认计划。周计划任务使用制作教师的个人指导，不再存在集中式负责人交接及借用他人提示词的规则。

## 非职责

桌面更新服务负责获取和验证指导包，运行时按本合同选择版本。AI 密钥由本地供应商配置管理，日计划、周计划和候选确认由各自业务模块管理。

字段新增后的适配界面、指导继承展示和历史版本保留期限在实施规格中细化；未获确认不能增加教师任意改写整段协议的能力。

## 实施状态与规格接续

2026-10-17 D2已确认三类日计划能力分别明确触发，首片仅提供对应三类个人字段指导；普通保存、采用候选或修改指导不会自动发起下一类AI。可配置OpenAI兼容接入、默认指导本地适配与接口草案见[D2规格](../specs/desktop-ai-daily-plan.md)，不据此开放周任务或改字段结构；产品决定已确认，[E1–E5工程规格](../specs/desktop-ai-engineering.md)设计核查完成，后续W1数据基础与W2本地提示词已完成限定环境工程核查，见[W2核查](../bootstrap/desktop-d2-w2-review.md)；任务执行/候选/界面及真实AI未验。

2026-11-08 的桌面功能包已通过源码及合成核查。正式来源、公钥配置和实际发布仍待安排，见 [Windows 教师反馈核查](../bootstrap/desktop-teacher-feedback-repair-review.md#第五批-6-提示词功能包接续)。既有 [提示词实施规格](../specs/prompts-implementation.md) 与 [协同索引](../specs/ai-capabilities-implementation.md) 保留历史实现及验收身份。与 v2 兼容的字段适配、候选采用和默认修订保护可作为复用审查依据。

旧规格须先映射到本 Contract 与 ADR 0004，不能直接作为桌面实施指令。本次不宣称桌面迁移或验收完成；后续入口见[Architecture v2 实施入口](../bootstrap/architecture-v2-readiness.md)。
