# 提示词 Contract

状态：Architecture v2 有效 Contract，2026-10-08；依据[ADR 0004](../adr/0004-local-desktop-architecture-proposal.md)。本地运行方向已接受，实现和验收仍需分别记录。

## 职责与数据归属

应用维护各 AI 任务的输入变量、输出字段名称与格式，以及默认生成指导。使用者拥有个人字段生成指导，可以修改指导内容，不能删除或重命名字段，也不能改变返回结构。

当前优先支持教案拆分、活动过程年龄适宜性调整与日计划其他活动生成。周计划游戏选取与补足、其他栏目及主题建议保留对应提示词能力边界，按后续周计划规格实施；不因此把周计划列入当前每日活动计划切片。游戏观察记录的任务、字段与流程尚未确认，本模块不预设其提示词。

具体拆分为几个实际 API 请求在调用规格中细化，不凭提示词列表增加调用次数。

## 输入与输出契约

输入为任务类型、本地使用身份和所需版本；输出为可执行的系统字段契约、实际采用的指导及版本、适配状态。个人提示词保存于本地数据，由 WebDAV 快照规则管理跨设备接续；不设同班教师互相查看或编辑个人指导的能力。

字段结构约束属于应用，AI 返回值须由程序校验，不能只在提示词中要求 JSON 就假定符合契约。个人指导不得绕过应用会话校验或计划确认流程。

## 更新规则

应用提供新默认模板时，提示使用者选择是否接受或覆盖个人指导，不静默覆盖个人内容。普通指导文字更新可拒绝，继续使用个人版本。默认模板的发行、版本获取及桌面适配方式在规格中确认，不依赖园所管理员在线修改。

必需字段变化时保留个人文字，提示适配；适配完成前暂停对应 AI 操作。手工编辑、保存不受此限制。字段适配状态必须能被本机 API 与本地执行组件一致识别。

待执行任务使用最新有效配置与已适配提示词；已开始任务保持启动版本，记录实际使用版本。改变提示词不自动重生成已确认计划。周计划任务使用制作教师的个人指导，不再存在集中式负责人交接及借用他人提示词的规则。

## 非职责

本模块不执行网络调用，不保存 AI 密钥，不直接修改日计划或周计划，也不替教师确认候选。

字段新增后的适配界面、指导继承展示和历史版本保留期限在实施规格中细化；未获确认不能增加教师任意改写整段协议的能力。

## 实施状态与规格接续

2026-10-17 D2已确认三类日计划能力分别明确触发，首片仅提供对应三类个人字段指导；普通保存、采用候选或修改指导不会自动发起下一类AI。可配置OpenAI兼容接入、默认指导本地适配与接口草案见[D2规格](../specs/desktop-ai-daily-plan.md)，不据此开放周任务或改字段结构；产品决定已确认，[E1–E5工程规格](../specs/desktop-ai-engineering.md)设计核查完成，后续W1数据基础与W2本地提示词已完成限定环境工程核查，见[W2核查](../bootstrap/desktop-d2-w2-review.md)；任务执行/候选/界面及真实AI未验。

既有[提示词实施规格](../specs/prompts-implementation.md)与[协同索引](../specs/ai-capabilities-implementation.md)保留原实现、产品决定和验收状态；未与 v2 冲突的字段适配、候选采用和默认修订保护继续作为复用审查依据，桌面默认模板更新机制须重新映射，不能直接沿用云端管理员操作链路。

旧规格须先映射到本 Contract 与 ADR 0004，不能直接作为桌面实施指令。本次不宣称桌面迁移或验收完成；后续入口见[Architecture v2 实施入口](../bootstrap/architecture-v2-readiness.md)。
