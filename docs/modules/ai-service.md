# AI Service Contract

## 职责与权威数据

本模块拥有教师个人 AI API 地址、模型、加密密钥及配置版本，统一处理网络调用、结果结构校验、失败分类和调用元信息。不拥有计划的业务确认权。

对 OpenAI 兼容服务的接入是已确认方向；具体采用的协议、接口路径和兼容范围尚待接入规格确定，不默认所有供应商均支持同一接口。

## 调用契约

调用方提供任务类型、操作者和计费配置所属教师、来源内容及版本、输出字段契约、实际提示词版本。返回经校验的候选结果或分类错误，以及实际配置版本、耗时等元信息。业务模块决定是否采用。

- 日计划操作使用当前教师配置。管理员发起日计划 AI 操作也不能静默使用原教师密钥；其配置可用性在操作前检查。
- 周计划自动操作使用当前负责人配置和个人提示词，允许负责人离线调用并产生其 API 用量。
- 教师停用、负责人调班或交接待接受时不得继续新发自动调用。
- 字段契约未适配时暂停对应任务。
- 配置修改不自动重新生成已确认计划；待执行与执行中配置版本规则按 ADR 0002。

管理员是否拥有备课配置界面属于实施规格问题；没有明确可用配置时不能通过借用他人密钥绕过。

## AI 与教师边界

AI 可拆分教案、调整过程年龄适宜性、生成活动、选取和补足游戏、建议主题及生成周计划栏目。AI 不能代替教师确认，不能将候选直接设为正式内容。

候选不足可生成游戏名称、目标和指导，但必须标记为 AI 补充；不能伪造日计划引用。AI 失败保留已有内容，不能阻断手工备课。

## 失败和恢复

鉴权、额度、配置错误暂停；明确可重试的临时失败有限重试。无法确定供应商是否已经处理的超时或进程中断不自动重发，提示可能重复计费并允许手动重试。

JSON 无法解析、必需字段缺失等输出错误须区分于网络错误；具体是否重新调用、次数上限和费用提示在实施规格中确定，不默认无限纠错调用。

一个工作进程采用受控调用并发。AI 调用不持有长数据库事务；队列和结果持久化不提供外部供应商“恰好一次”处理保证。

## 安全边界

密钥加密保存，解密密钥与数据库分开。仅在获授权任务中使用，不完整回显，不写入日志、错误或前端持久存储。个人配置版本标识不等于保存一份明文密钥。

仅允许公网 HTTPS API 地址，校验实际连接目标和重定向，阻止本机、内网、云元数据等地址。网络校验必须覆盖 DNS 解析与跳转，不能仅校验用户输入的字符串外观。

日志默认只记录任务、操作者、配置/提示词版本、状态、耗时及脱敏错误；业务需要的候选内容由日计划或周计划模块保存。
