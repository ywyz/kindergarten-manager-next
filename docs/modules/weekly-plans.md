# 周计划 Contract

## 归属与唯一性

同班、同学期、同周只能有一份有效周计划。重复创建打开已有计划；原创建教师是初始负责人，同班其他教师只读，可导出已确认版本，但不可编辑或确认。管理员可编辑删除，但新内容仍由负责人确认。

可恢复删除与重新创建不得产生两份有效记录。恢复存在冲突时须先处理冲突，不能静默合并或覆盖另一份计划。

创建者和当前负责人分别保留。负责人调班或停用后暂停自动 AI，完成接管接受后由接管者维护确认，使用其配置和提示词。

## 内容来源与生成

| 内容 | 来源与生成规则 |
| --- | --- |
| 主题名称 | 教师提供，AI 可建议但不自动覆盖 |
| 晨间谈话、集体活动名称 | 按日计划日期对应 |
| 户外游戏 | 汇总全班日计划晨间活动，AI 选两项集体游戏、一项自选游戏；日计划的一项集体加一项自选不改变周计划数量，候选不足按缺项及补足规则处理 |
| 重点区域 | 从同班任意教师、任意日期的集体活动后区域、户外或专用室游戏选取 |
| 已引用游戏的目标与指导 | 读取所引用日计划的对应内容 |
| 材料 | AI 根据所选游戏名称、目标、指导、支持策略及班级年级，优先提取已明确提到的材料，不足时生成补充建议；负责人编辑确认 |
| 不足游戏 | 列出已有内容并提示不足；允许 AI 补足名称、目标、指导，标记 AI 补充 |
| 本周重点、环境创设、生活习惯培养、家园共育等其余栏目 | AI 根据本周日计划生成，负责人编辑确认 |

引用日计划的内容保留来源和版本；AI 补充没有伪造的日计划来源，仅存在于周计划。来源补齐后自动重选可以替换补充项目，新结果仍须确认。

日计划多个游戏共用目标与指导时，引用组内某个游戏须保留该组共用内容和来源，不编造专属指导。“自主游戏”与“自选游戏”为同一类别。

同名游戏保留各日计划来源记录；周计划选取时，同类别同名游戏只占一个名额，由 AI 选择一个具体来源并携带其整组目标与指导，负责人可改选其他来源。不跨来源拼接冲突内容；名称相近但不完全相同的游戏先不自动合并。

材料保留生成依据，只存周计划，不回写日计划；提取与补充均进入候选采用及负责人确认流程，不把支持策略全文直接当材料。具体映射和例子见[最小实施规格](../specs/manual-plans-and-word-export.md)。

## 保存、生成与确认

日计划保存或删除触发待更新，确定性字段同步到待确认内容。最后一次相关保存后等待 30 秒开始 AI，支持立即更新但仍排队。

保存以下不同内容：

- 上一份已确认版本：可导出，不能被自动更新原地改写。
- 当前人工编辑内容：不因新 AI 返回而直接丢失。
- 最新候选结果：附来源版本、配置/提示词版本及来源是否过期的信息。

采用候选时，游戏自动重选允许覆盖人工游戏内容；其他人工修改的 AI 栏目保留，由教师选择替换。主题名称始终由教师决定。

生成期间来源变化，结果不能作为最新内容确认，应处理最新来源。确认时再次检查来源版本及维护权限，避免编辑期间的变化被遗漏。管理员修改日计划或周计划都使新内容待确认，原确认不自动覆盖新内容。

## 状态与导出契约

任务进度、完整性、来源新旧与确认状态分开表达。例如一份周计划可以同时拥有“已确认上一版”和“AI 更新失败”，两者不矛盾。

| 情况 | 已确认的行为 |
| --- | --- |
| 更新等待或生成中 | 可导出上一份已确认版本，导出前提示未包含最新变化 |
| AI 失败 | 保留已有内容，可重试或手工修改；不强制等待成功 |
| 缺项或当前内容未完全更新 | 负责人可明确确认当前已有内容后导出，记录缺失和未更新之处 |
| 未确认 AI 候选 | 不直接用于导出 |
| 候选基于旧来源 | 不可冒充最新候选确认；允许显式确认不完整内容的规则不取消来源标识 |

确认不完整计划不等于后台任务成功，也不等于内容完整；界面不能用同一状态掩盖区别。具体自动任务完成后如何呈现新一轮候选在 UI 规格中明确。

## 非职责

不反向修改日计划，不持有所有教师的密钥，不通过自动生成决定产品权限，不将文档导出结果导回为数据权威。
