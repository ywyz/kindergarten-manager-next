# Word 导出 Contract

## 固定模板与证据边界

用户指定以下本地文件作为模板参考：

- `/home/ywyz/桌面/中四班 备课.docx`
- `/home/ywyz/桌面/周计划.docx`

此前只完成文字和表格结构比对，未进行渲染和打印版式验证。本次最小规格工作再次只读核对了 OOXML 栏目与结构，未复制、编辑或上传模板，也未执行兼容性验证。这两个路径是参考来源，不是生产运行时必须存在的路径。

必须保留两列日计划表格、周计划表格结构、栏目与主要格式，允许内容增长自然分页。周计划保留周一至周五日期列，遇周末上课增加对应日期列并按日期排序；假期注明，不截掉第六、第七个上课日。样例包含周日上课及假期合并单元格，不能把周计划固定解释为每周一至周五必有五份日计划。

## 输入与输出

输入为有权限访问的计划、明确的内容版本、筛选范围、固定模板及日计划活动过程比较基准；输出为 Word 文件。导出不修改计划内容、来源关系或确认状态。

应用用户权限仍须在导出入口及文件下载处生效。已确认同班教师可导出他人的日计划及已确认周计划，不获得编辑或确认权限；调班后的历史访问限制不变。

表头中的园所名称、班级教师名单及保育员姓名由管理员维护；日计划显示创建教师，周计划显示班级教师名单和保育员。周次沿用实际日期所在的学期周次算法，不能从表头日期跨度或所显示列数重新计周；表头起止日期显示该周第一个至最后一个上课日，依据有效日历，不因某日缺少日计划而缩短范围。

## 范围规则

- 日计划支持单日、按周、按月及自选日期范围；严格筛选范围内日计划。内容缺项时先提示，教师确认后仍可导出，保留空栏目，不自动补写；这不改变周计划的负责人确认规则。
- 周计划支持单份及按日期范围合并；以其上课日期是否与范围相交选取整份计划。
- 选择单日会选出包含该上课日的整份周计划；跨周、跨月不裁切周内栏目，每份只出现一次。
- 未确认候选不导出；上一份已确认版本可以导出但提示存在更新。
- 当前内容不完整也可由负责人确认后导出，记录缺项或未更新内容，不强制 AI 成功。

无匹配计划时提示，不生成空文件，不扩大日期范围。日计划按日期升序合并，周计划按周起始日升序合并；每份计划从新页开始，份内长内容自然分页。导出大小上限及文件清理策略留待导出实现前细化。

## 标红与兼容

日计划活动过程以原始教案拆出的过程为基准，比较教师最终采用内容，导出时将改动标红。活动主题必须正确填充，不保留旧系统字段遗漏。

已确认：无原始拆分基准时按最终内容导出，不标红并提示无法比较；有基准时新增和替换后的文字标红，纯删除不显示已删文字，纯段落移动和仅格式变化不标红，不增加删除线。

目标环境已确认为 Windows 上的 Microsoft Word、Ubuntu 上的 LibreOffice 兼容打开，不要求实体打印；具体版本及字体在执行时记录。具体生成库、模板清理及已确认字段映射的渲染效果待最小验证确定。首版不提供任意模板上传编辑，不引入 Typst 转换。

已下载文件是时间点副本，后续计划变更只能通过重新导出体现。文件临时保存和清理策略待实施规格定义，不把导出文件当业务主数据。

实施映射见[最小实施规格](../specs/manual-plans-and-word-export.md)，案例与通过标准见[模板验证计划](../specs/word-template-validation.md)。计划落盘不代表验证通过。
