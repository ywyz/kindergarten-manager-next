# 2026-11-14 教师测试反馈修复报告

本轮从 `b5a1ea8` 开始。OpenCode 与 Command Go 使用 DeepSeek V4.1 Flash max 实施，Codex 独立审核。预览更新在 `fix/preview-update` 验证，教师流程在 `dev/0.1` 验证。

## 反馈与修复

| 项目 | 改动和验收范围 |
| --- | --- |
| 应用内更新 | 先检查 Windows 旧进程句柄是否已结束，再读取仍在运行进程的映像身份，修复已退出进程被误判为超时。安装前检查独立更新器的发行信任配置。旧目录明确恢复后允许再次安装。窗口说明下载、确认安装和未确定回执。检查和下载由宿主 HTTP 客户端处理，合成回归核对应用内路径；教师机上 IDM 弹窗待复现。 |
| 工作台 | 侧栏分别打开日计划和个人待办。圆形按钮标记完成，方框用于批量选择。已归档待办可取消归档，保留完成状态并按原请求核对回执。 |
| 协作管理 | 管理员可更改园所显示名称，保留园所与班级稳定 ID。提示词发布显示中文任务和字段名称。兑换后显示已绑定园所、待选或现有在线班级，教师从园所目录选班。本机资料继续由 SQLite 管理，MySQL 保存在线身份、班级关系、在线游戏配置及共享周等协作数据。共享周保留晨谈、集体活动名称与游戏等已批准字段。 |
| 设置 | 提示词按任务分组说明并显示中文字段。常用的 AI 配置、班级游戏配置默认展开。已连接的教师可经原预览和确认流程发布本地班级游戏配置。 |
| 日活动计划 | 拆分使用结构化正文并保留原文忠实性校验。其他活动生成成功后直填当前安全草稿，教师核对后保存。集体活动后游戏指导承接已提供的集体活动内容，缺资料时直接给出可执行指导。日计划定向修改对话框移至顶部。晨间 Word 分组呈现，并核对下午区域、游戏名称和重点观察字段。 |
| 周计划 | 周次确定后读取本人日计划并展示游戏备选。每日最终格支持跟随、覆盖和明确清空。各表单可以分别发起 AI，进度按当前执行身份读取。顶部保留保存、返回、导出和查看共享周计划。导出弹窗常规操作为关闭和保存并生成，由后者创建历史快照并生成 Word。 |
| 课程审议 | 原稿拆分和审议建议走结构化输出，当前记录及执行的进度可以在面板查看。拆分校验保留原话和原文顺序。 |
| 游戏观察 | 生成和改写提示要求正文和评价去掉模型局限说明，评价引用可观察表现。保留旧规格允许的匿名情境对话和动作衔接，候选区独立显示补写核对提示。 |
| 一对一倾听 | 本次测试报告未试用，本轮无对应修复项。 |
