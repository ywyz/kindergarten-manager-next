## C1：角色入口与页面

逐一以教师、待分配、管理员进入设置；本人 AI 配置和个人指导均可见且可读，待分配不被 class_id 限制。教师没有系统默认编辑；管理员有独立系统默认面板和管理员本人的指导，修改其中一个不会改另一个。真实查看 loading／失败重试和文字布局；前端 build 成功不算此项通过。

## C2：本人配置与密钥

1. 首次无 head，空密钥不能保存；输入合法 HTTPS 地址、模型和合成密钥，保存成功，输入立即清空，只显示是否已存及固定遮罩。ready 为“本地配置可用”，不声称连接供应商。
2. 重载页面，地址／模型与版本持久、完整密钥无回填；留空密钥只改元信息，保存后仍 has_secret。轮换另一合成密钥成功，版本按真实响应推进。
3. “清除已保存密钥”先取消，验证未变化；再确认，密钥状态清除，地址／模型保留。刷新后仍清除；已存在 head 清除后允许只存元信息。
4. 请求序列仅记录方法／状态／版本及 secret 字段是否省略，不记录值。失败时本页输入应保留；成功、卸载、退出／401／账号切换应清空。不存在浏览器持久存储、URL 或提示回显完整密钥的行为。

## C3：七任务与真实持久化

依次读七任务：教案拆分、过程适龄调整、日其他活动、周游戏、周栏目、周主题建议、周材料。每次字段以 API 的 based/latest 为准。首次只 GET 不自动初始化，只有“建立我的指导”写入；重复初始化不得新增个人版本。

显式初始化后，每个任务的全部字段实际输入并保存、刷新重读。选一个字段检查空串、换行和首尾空白原样保留；检查 8000 字符成功与 8001 不可提交或固定校验错误（记录是 UI 阻断还是 HTTP 422，不声称另一个层也已执行）。无变化不提交；普通保存只提交变更字段。检查 HTML 样文字按文字呈现。记录 personal_revision、based/latest contract 和 default revision。

## C4：管理员默认与个人比较

选至少两字段的任务，教师先保存两份可区分个人文字。管理员在独立面板只改默认文字并“发布修改”；教师个人文字不变，出现更新比较。

教师只勾一个字段接受：显示将覆盖内容，接受后选中字段变默认、未选字段原样保留。再发布一次，教师“保留当前指导”：个人文字／personal_revision 不变；重复拒绝幂等，之后主动打开比较仍可接受。普通草稿 dirty 时先保存或显式放弃，再接受／拒绝；不能静默删草稿。管理员本人指导不会被默认发布自动更新。先私密备份原默认，收尾只通过 UI 追加恢复修订，不回退数据库指针。

## C5：真实契约适配（当前夹具受阻）

当前只部署真实 v1；v2/v3 发布不在本轮普通部署操作内。不要导入真库测试模块、直接写库或改 registry。将 C5 及下面 V1 契约场景标为“受阻：缺经单独授权的真实发布夹具”，其余案例继续。

托管者另行准备夹具后的必需步骤：在发布前初始化并保存 v1 个人文字；系统发布带同名、新增和移除字段的 v2 及完整匹配默认；刷新后旧文字保留、旧字段可普通保存但状态仍待适配，接受／拒绝不可用。打开完整适配：同名保留、新增预填、移除原文可见；关闭不提交、不标已适配，修改过的关闭草稿仍计入离开确认；完成时提交完整最新 map、真实 expected 与 target，成功才变 current。飞行窗口普通 textarea、放弃和重复写按钮确实 disabled，不强行 mutate disabled 输入。

### V1／U3：双草稿 DOM 与处置补验

这是第五轮修复的必需产品证据，待真实夹具具备后执行，不能以模板绑定或 356 项脚本宣称通过。

1. 会话 A 待适配→打开适配→同名 f1 输入 A→关闭适配保留→普通 f1 输入不同 B；会话 B 完成适配到最新，A 普通保存得真实 409，companion GET 读 current 完整 map。点“保留我的修改，以最新版本作为提交基线”：**B 在普通框、A 在只读参考区，两份文字实际可见**，提示真实，不自动合并／提交。返回有确认；取消留在页面。保存 B 后 A 仍可见且离开仍确认；明确“放弃适配草稿”后页面干净。另一次载入最新明示放弃应清全部残留。
2. 重建同字段相同 A/B：只留一份，无重复参考行；不同字段双 dirty：两份文字均保留，保存覆盖正确字段。仅普通 dirty、仅适配 dirty、纯预填关闭，各按既有语义，不制造虚假未保存。
3. 会话 B 只普通保存、仍待适配；A 得 409 后保留两份。普通保存 B 后重新打开适配，参考 A 回可编辑面；完成适配后干净。
4. 另行发布收缩契约移除已编辑字段，409→保留后普通文字、同名适配 A、被移除字段草稿都可见；普通保存不能提交移除字段，参考文字仍保留至明确处置。

每小例记录真实字段名、版本演进、文字标记所在 DOM 区域、按钮可用状态和返回确认；不使用脚本给被锁输入赋值模拟用户路径。

## C6：真实双会话冲突、旧响应与刷新失败

- 配置：A/B 读相同版本，A 保存，B 输入不同元信息／合成密钥后保存得 409。B 输入保留、最新比较独立显示；未明确选择前不允许再写。“保留输入，按最新版本重新保存”只更新基线，必须另点保存才写；“载入最新配置”确实替换元信息并清密钥。两个分支均执行，记录服务端真实版本。
- 个人指导：同任务 A 保存后 B 旧 revision 写得 409；B 文字保留，显式保留／载入分流，不自动 rebase／重发。保存成功后刷新若失败，仍显示已经保存的写结果，不让用户盲目重复写。
- 管理员默认：两个管理员页面同 revision，A 发布后 B 得 409；同样检查保留／载入与显式再发布。比较过程中另页再发布默认，旧 accept target 应失效，必须重新载入并勾选。
- 用已有浏览器拦截能力延迟**真实请求的响应交付**，切换任务／默认面板／离开后再释放旧 success／error／finally，新任务文字、提示及 loading 均不被旧响应污染。延迟／强制网络失败记录为前端模拟证据；普通读写持久化仍须真实服务器。工具无拦截能力就标受阻，不安装新框架、不替换整个 mock 页面。
- 参考区／普通／适配各有未保存文字时，设置返回确认准确；取消返回保留，显式处置最后一份才无确认。账号退出后再登录另一账号，不继承上一账号草稿或密钥。

## C7：错误与原有手工链路

真实教师访问管理员默认应 403；通过已有同源请求能力只送不含密钥的非法输入检查固定 422，不输出原始 payload。无会话设置读为 401；双会话用现有“修改密码”撤销其他会话后，旧页面触发请求得 401 并退出、清空输入密钥，私密记录并同步更新测试密码，不能让后续账号凭证失效而不交接。

503／DECRYPT_UNAVAILABLE 的缺／错主密钥真实服务子例当前受阻，只有托管者单独获授权后切换夹具才可执行；错误提示不得显示原始异常。若使用浏览器合成错误，只能标前端模拟。不能将正常环境没有 503 当作降级通过。

通过原设置 UI 更新教师姓名再恢复；密码用合法原密码改为临时密码再改回，验证真实登录与其他会话撤销。以负责人选择既有合成日／周计划，私密备份当前版本，通过合法 UI 保存日计划、保存周草稿，现场读取版本再追加恢复；不改不可变基准、不直接改确认快照。通过真实 UI 分别下载日 Word 和已确认周 Word：中文文件名、非空字节、ZIP 完整性与 SHA-256；这次为设置改动后的链路冒烟，不能替代历史 I5 逐页证据或完整 W6 非空材料验收。
