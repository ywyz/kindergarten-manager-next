# 2026-11-24 教师免码反馈与诊断日志验收

本轮从 11 月 22 日签名预览的源码 `9a43f22` 开始。教师通过工作台「在线反馈」报告问题，提交前可以查看附带的诊断日志，也可以取消附带。管理员登录协作管理站后，在对应反馈中查看详情。[产品规格](../specs/desktop-webdav-and-online-feedback.md#应用内在线反馈)

## 验证环境

桌面和浏览器验证使用 Windows、合成教师档案、Edge、本地 API 和一个单独的 HTTPS 协作站。该站运行实际协作服务，使用独立 MySQL 8.4.11 数据库和合成管理员。旧回执由 11 月 22 日的源码在迁移到 `0007` 的数据库中提交。

## 升级与故障回传

- 在带旧反馈的数据库上执行 `0008_feedback_diagnostics.sql`，使用旧客户端的原请求重试，取得同一条记录的回执。保留旧反馈码配置时，新版省略反馈码、旧版携带已停用的码，两种请求均能提交和重试。
- 用实际本地 API 创建、保存一份合成日计划，再用过期版本尝试保存。日志记录了成功和 `VERSION_CONFLICT`。通过 HTTPS 提交后，管理员读取到相同的事件、顺序与时间，合成计划正文没有进入日志。
- 并发记录 230 次操作，重新打开日志存储后，反馈预览仍取到最近 50 条。未识别的错误值归为 `UNKNOWN_ERROR`。
- 在合成档案 A 读取日志途中暂停磁盘读取，同时绑定合成档案 B。初次复核能复现旧目录的较慢读取覆盖新目录。修正后用相同时序重试，B 只显示 B 的倾听保存操作。
- 在 Edge 中从工作台打开「在线反馈」，默认勾选「附带诊断日志」。本例展开的三条日志与提交请求、MySQL 保存的记录、管理页面显示的日志逐条相符。首次请求成功写入后模拟连接中断，关闭表单并产生另一条冲突事件，再打开重试，沿用了相同请求和原来的三条日志。新反馈刷新了日志窗口。取消附带后，请求不含 `diagnostics`，管理端显示「未附带」。
- 新档案还没有诊断事件时，默认勾选也能取得反馈回执，管理端可以正常查看。普通教师无法匿名读取管理端的反馈列表。
