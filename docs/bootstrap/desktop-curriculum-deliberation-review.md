## 回修

- Command Go 绑定输入代次与已保存版本。真实 WebView2 中延迟预览响应，期间新增输入会使该预览失效。Word 下载与原生另存为之间加了失效校验。预览或 Word 遇到 409 可读取并核对最新版，原输入可保留。
- OpenCode 恢复校样的最低行高、栏内对齐、固定提示、分节与段落网格。Codex 用同一合成素材隔离试验，确认 Word 的 `adjustLineHeightInTable` 兼容设置恢复两栏的实际续页位置。预览与 Word 共用教案正文判定，忽略只有空白与不可见格式字符的材料。实际正文保留段落、编号和有效的组合字符。
- 桌面迁移与静态专项在短根 11 项通过。先前长根的一项夹具在写测试路径时失败，短根以同一组用例复跑通过。
