- 桌面迁移与静态专项在短根 11 项通过。先前长根的一项夹具在写测试路径时失败，短根以同一组用例复跑通过。

## 2026-11-10 课程审议 AI 独立核查

基线为 `codex/teaching-documents-design` 的 `1cc91c1af48f0b61da732b9663f79e2731f5b7c7`。OpenCode 续接上一轮原生后端会话，负责三段模型指导、现有本机任务执行器接入、输入投影、候选校验、联动和 0018 迁移。Command Go 续接上一轮原生前端会话，负责整理核对、审议预览、选段采用、原保存和导出流程的接入。Codex 使用独立合成档案、假供应商和回环守卫做实际执行验证。

### 首版反例与回修

- 真实执行器的合成探针发现粘贴教案中的署名到达假供应商。原稿拆分 ID、审议意见及选区标识也各有接口差异。回修后，署名随原稿在本机重组，假供应商只收到本次所需资料。拆分、审议和选区任务可依次完成。
- 首版仅按整段匹配联动，选择段内文字时没有更新主表。手工编辑对应栏后，旧结构还可能覆盖手工内容。回修后按段 ID 和段内偏移联动，并核对对应栏的当前文字。无法安全联动时保留手工文字并提示。单独修改理由也保留无关的目标、准备勾选。
- 0018 首版丢失 0017 已有的倾听外键及若干日计划索引，复制旧倾听观察目标任务时中止。回修后核对源与目标 SQLite 的外键、索引、触发器和倾听任务谓词。含倾听目标任务、周计划执行及候选的合成旧库升级后，旧记录逐行一致。
- 原生另存为首探针输入未选定目标目录，Windows 将一份合成文件保存到默认文档目录。Codex 按创建时间、合成正文和 SHA-256 核对后，将这一份文件移入隔离验收目录。复跑限定原生对话框的拥有进程，并在实际写入前验证测试路径归属。
