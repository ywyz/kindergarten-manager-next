## 2. 首轮验收范围与结果记录

- 对后续确定的单一服务／模型，拆分、适龄调整、其他活动各完成一个真实样本，依次进行；首轮预期三次业务触发。这个数量描述一轮验收范围，不是产品日常调用配额，也不是供应商计费硬限额。多服务实际测试范围另行明确，不由候选数量自动倍增。
- 每步完成候选审阅、比较／采用和保存核对后，再进入下一类。失败或结果不明先停下来核查，不自动补足成功样本、不另加比较模型、压力测试或收费纠错。
- usage、可获得费用、返回模型和耗时只作真实结果记录；缺失标“不可得”，不估造。缺少usage或账单延迟本身不判定接口失败，也不再作为预算前置条件。
- 本轮不规定token或费用预算，不测算或开发预算控制，不作价格、账户可达性或服务可用性承诺。
- 已确认的连接10秒、单次尝试120秒、请求／响应各1MiB，以及明确未发送时的有限重试规则保持；它们是现有工程保护。本轮不调限额、不扩大自动重发范围，可能已发送的结果不明请求仍不自动重发。

### 4.1 拆分用原始教案

以下整段复制到原文框；不预先把六字段答案写入正文。

> 活动名称：找朋友——按形状分类
>
> 适用年级：中班。
>
> 活动目标：能分辨圆形、三角形、正方形，并尝试按形状分类；能用“它是……形，所以放在这里”说明自己的选择。
>
> 活动准备：大幅圆形、三角形、正方形图形卡各若干；三个分类垫；玩具小熊一只。图形卡颜色和大小可以不同，材料不放入口中。
>
> 活动重点：观察图形的外形特征，并按形状找到相同类别。
>
> 活动难点：在颜色、大小不同的情况下，仍能按形状分类。
>
> 活动过程：一、看一看。小熊带来不同图形，请幼儿说出看见的形状，教师用实物引导观察边和角。二、分一分。教师示范把一张卡放到相应分类垫上，幼儿分组轮流摆放，每人说明一次选择理由，教师对犹豫的幼儿提供比较提示。三、找一找。共同检查三个分类垫，把放错的卡重新分类，再从活动室中寻找相似形状的物品。最后共同整理材料。

只检查拆分忠于原文、不补造实际教学事实，六字段形状符合契约；不要求模型输出固定措辞。预览时可在过程末尾添加“教师验收编辑：先观察，再操作。”，再比较／采用，用以区分未经编辑的模型基准与正式过程。此为验收编辑，不冒充实际课堂观察。

## 6. 故障停止与保留现场

以下任一条件出现时，停止后续样本，先核查原因，不换地址／模型试探，不点同类重试：

1. 实际服务／模型／协议未明确，或没有后续真实调用授权。此时不发送，记“未执行”。
2. 鉴权、额度、限流、HTTP错误、连接／TLS／DNS失败、拒绝重定向，或输出截断、拒答、非JSON、schema失败。记录实际错误及发送证据，不主动制造收费失败样本。
3. 超时、失联、用户停止等待、结果不明或任务状态无法持久化。保留真实状态，不把停止本地等待写成供应商已撤回，不自动重发。
4. 无法解释的额外任务／请求、可能已发送的重复尝试、自动采用、来源／版本冲突、未选字段被覆盖、密钥或完整材料进入不应出现的日志，或白屏等影响继续操作的问题。保留同一现场交原OpenCode定位；不复开无证据的历史排查。
5. 候选质量不适合材料／目标年级，用户不愿采用，或用户要求停止。保持候选可查，不为凑齐成功样本自行补发。

现有应用只对明确未发送的临时错误有限重试。本轮不改该实现；若出现retry_wait或多attempt，先暂停后续样本，区分连接准备与实际已发请求，不把所有attempt算成收费请求，也不把可能已发重试说成免费。usage缺失或账单延迟如实标不可得；返回模型与配置模型差异若无法解释，先核对服务身份。

停止后先保护正文／候选草稿，按已有“停止等待并退出”及保存／关闭协调收口。保留paused／failed／outcome_unknown／succeeded等实际状态，不改数据库、删除任务、清库或强杀冒充正常退出；未解决草稿或收口失败仍遵守原拒绝关闭保护。任何再次收费尝试都先说明原因和拟操作，不自动延续验收。
