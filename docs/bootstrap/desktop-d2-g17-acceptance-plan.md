## 1. 验什么、用什么

- 只验证一套用户选定的公网HTTPS、OpenAI兼容配置和一个明确模型：三类任务的真实响应→候选→比较／采用→保存；随后本地重启读回和Word导出。不同供应商／模型另计一次独立验收，不用这一轮概括所有兼容服务。
- 使用已验普通完整包build/desktop-d2-normal-r01/package/KGNext-D2Verify/，入口d1_main。EXE SHA-256 e843d11b38ff87fc4876313aad8a20cb60912ff73c61b1f35d908dae81a6ba5c；182文件，清单99ae429a998fdae01a187bf9c62a8ebedf718525b3c4b1ce3c612f72f0fdfbd2。执行前只读核对，不重建或覆盖旧包。
- 全新独立数据根及LOCALAPPDATA，APP_DISABLE_DOTENV=1；不用默认教师库、原human根或其中已保存的合成供应商配置。不走manual-ai入口、不加synthetic-provider参数、不关闭TLS／公网目标检查、不加代理或新组件。
- 只有本方案中的虚构材料可发送。教师、园所、班级均为虚构，不含真实幼儿／教师资料、照片、历史业务库或其他日期教案。密钥由用户在应用内填写，聊天、仓库、截图与验收记录都不保存密钥或Authorization头。
- OpenCode的Go套餐DeepSeek V4.1 Flash是既有实现模型，**不代表应用供应商已选定或应用调用已授权**。本轮只写规划／核查文档，无需再调用OpenCode或改实现。

## 2. 建议调用次数与用量上限

| 项目 | 本轮建议边界 | 计数及落实方式 |
| --- | --- | --- |
| 业务触发 | 总共最多3次：拆分1、适龄1、其他活动1 | 严格串行；每次完成结果／用量／内容核对后才可点下一类，失败不补足成功数 |
| 已发或可能已发的外部请求 | 最多3次POST /chat/completions，每类最多1次 | 可能发送即占用该类唯一名额，超时／停止／失败不退还；无手动retry、重建任务或同类第二次点击 |
| 单次输入 | 最多6,000 input/prompt tokens | 包含完整system、默认／个人指导、schema和序列化业务输入，不能只算教案正文；先用受测模型可靠的离线分词器或供应商可强制的输入限额核对，不按字数猜算 |
| 单次输出 | 最多2,000计费output/completion tokens | 包括供应商计入输出的推理等部分；必须确认供应商如何硬限制，不能只在提示词里写“请简短” |
| 本轮token总量 | 输入最多18,000，输出最多6,000，合计最多24,000 | 三项同时满足；不以缓存命中承诺降低预算，不把total与input/output重复相加 |
| 本轮费用 | 总共最多人民币1.00元，包含失败／不明请求可能费用 | 该值是建议预算而非报价；先记录选定服务的有效计价和硬限额证据。非人民币账户在授权中另写原币确切上限，不自行换算或充值 |
| 次数以外的调用 | 0 | 不为连通性、列模型、余额查询、纠错、重试、模型比较、压测或故障注入新增外部API请求；设置保存不做试调用 |

达到任一限额即停止；不得用“这次失败可能免费”“还有剩余次数”扩大另一项限额。每次发送前按供应商实际计费规则和输入／输出硬上限预留该次**最坏费用**，连同已用／尚未结算占用不得超过1.00元；无法给出可靠上界就不发。未知计费请求继续占用其最坏预算，不能按0元或0 tokens释放。

若完整提示词与材料已超过单次输入预算，不截断系统契约、指导或原文来勉强发送；先记录超出项，再讨论缩小虚构样本或调整待授权预算，未经确认不继续。

**现有实现的限制必须先说明：** 当前[ai_transport.build_request](../../backend/app/local/ai_transport.py)只发送model、两段文本messages和stream=false，没有max_tokens／max_completion_tokens，也没有24,000-token或1元预算执行器。120秒与1MiB是时间／字节限制，不能保证token或费用上限；本地停止等待也不能撤回供应商已经开始的处理。

因此，这份方案中的token／费用上限**尚未由当前普通包强制落实**。实际执行前须取得受测供应商对该密钥／项目／模型可强制输入、输出及总费用边界的证据，并确认对当前无输出上限参数的请求仍有效。仅有软预算通知、延迟账单、提示词长度要求或事后usage不足以证明硬上限。若供应商不能落实，停在执行准备阶段；另行提出最小参数／预算控制方案并取得实施授权，由OpenCode实现、Codex核查后再执行。本轮不改协议、代码、数据库或包，也不擅自把硬上限降成事后观察值。

### 4.1 拆分用原始教案

以下整段复制到原文框；不预先把六字段答案写入正文。

> 活动名称：找朋友——按形状分类
>
> 适用年级：中班。
>
> 活动目标：能分辨圆形、三角形、正方形，并尝试按形状分类；能用“它是……形，所以放在这里”说明自己的选择。

>
> 活动重点：观察图形的外形特征，并按形状找到相同类别。
>
> 活动难点：在颜色、大小不同的情况下，仍能按形状分类。
>

只检查拆分忠于原文、不补造实际教学事实，六字段形状符合契约；不要求模型输出固定措辞。预览时可在过程末尾添加“教师验收编辑：先观察，再操作。”，再比较／采用，用以区分未经编辑的模型基准与正式过程。此为验收编辑，不冒充实际课堂观察。

## 6. 停止条件与停止后的处理

出现以下任一条件，不发下一类、不换模型／地址试探、不点同类重试：

1. 未取得后续真实调用授权；§3任一必需项未落实，尤其硬token／费用上限无法证明。此时零发送，记“未执行”。
2. 已达3次已发／可能已发，任一单次或累计token／费用达到或超过边界，或者下一次最坏费用／token无法在剩余额度内预留。正常完成3次也到此停止，不自动加做一次。
3. usage缺失／负值／含义不明，供应商账单延迟导致费用不可核对，或配置模型与返回模型差异无法由官方别名说明解释。保存可得事实，缺失记“不可得／待核对”，不伪造usage、不凭字数或120秒估计费用；该样本可记录协议结果，但本轮不继续消费或宣称预算核验通过。
4. 任一次鉴权／额度／限流／4xx／5xx、连接／TLS／DNS失败、拒绝重定向、输出截断／拒答／非JSON／schema失败。保留分类与发送证据；不主动制造收费错误样本。
5. 任一次120秒耗尽、停止等待、失联、结果不明，或任务状态无法持久化。未知结果继续占用其唯一调用名额和最坏预算，不按“已取消”当供应商撤回。
6. 出现自动retry_wait／重复attempt、额外任务／请求、自动采用、来源／版本冲突、错误覆盖未选字段、密钥或完整材料进入不应出现的日志；或者复发白屏等影响安全操作的现场。保留证据交原OpenCode定位，不复开无证据的历史排查，不通过改数据库收口。
7. 候选质量不符合该次材料与年级／地点约束，用户不愿采用，或用户要求停止。候选保持可查看；不为凑齐三个成功样本追加收费调用。

停止后先保护正文和候选草稿，通过既有“停止等待并退出”收口在途任务，按实际已发证据保留paused／failed／outcome_unknown／succeeded等状态。不得强制把未知改失败、删除任务或清库；有未解决草稿或清理失败时遵守既有拒绝关闭流程，不强杀冒充正常退出。随后核对本地记录、供应商已知用量及额度；供应商控制台撤销权限只能作为后续防新增手段，不能保证撤回已接收请求。当前授权不包含为未知结果另发请求查费用或重试。
