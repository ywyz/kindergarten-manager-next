## 逐页证据格式

每份记录：本轮ID、角色、浏览器UI入口、范围／确认版本、响应状态与警示、实际原件文件名、非空字节、SHA-256、ZIP CRC、软件版本、实际总页数、逐页截图与结论、Protected View／修复／转换提示、关闭后原件哈希。

逐页结论至少含：当前页归属哪份计划、内容是否连贯、表格／日期列是否完整、标红／原色是否符合预期、有无裁字／遮挡／越界／缺字／异常空页。截图必须能读到文字，必要时同页整体图加局部图，低倍率缩略图不能证明文字完整。系统字体是否实际替代需单独记录。

Protected View 如实记录有／无。页面视图能完成检查时不强求打印预览；不解除全局保护设置。遇工具技能的安全权限限制时记录具体阻塞与人工步骤，不把“启用编辑／打印”点击发送当作完成。不要将普通受保护视图误报为文档损坏。
