# 2026-11-22 教师反馈与依赖修复验收

本轮基于开发分支的 `e0bc2b4`。OpenCode 的 GLM-5.3 和 Command Code 的 GLM-5.3 Flash 分工修改源码，Codex 用独立检出、锁定依赖、合成教师档案和回环服务验证。桌面验证环境为 Windows 11、CPython 3.14.10 x64 和 Edge。浏览器运行应用前端并连接实际本地 API，桌面文件保存桥由合成宿主接收。AI 流程使用测试任务。[当前任务](../tasks/current.md)

## 教师日常操作

- 工作台的「日计划」先打开月历，教师点选日期后打开完整预览。以 11 月 22 日为本机日期，分别点选 11 月 17 日的已保存计划和 11 月 18 日的可备课空白日期。两次均打开所选日期，浏览期间没有写入请求。空白日期可填写原始教案，已有计划逐栏检查了两组晨间游戏、材料、集体活动、下午支持策略和一日反思。修改并保存晨间谈话后，从「任务」打开历史，再点击「导出 Word」。隔离宿主接收实际生成的 DOCX，核对文档 XML 中的该次修订、游戏名、主题、材料和支持策略。
- 日计划、周计划、游戏观察、倾听和课程审议均按当前记录读取 AI 任务与版本。周计划查看已确认版本，倾听和审议每次实际保存保留完整版本。重复回执沿用已提交版本，冲突不会写入历史。
- 针对长计划测量了初次打开时的按钮位置。宽窗 1166×782 下，四个主操作在右栏依次纵排。窄窗 760×560 下，初版需要向下滚动约 4,500 像素才能操作。回修后四个按钮位于首行，距窗口顶部 11 像素，「任务」与「日历与已保存计划」在下一行。由已保存计划返回时保留原选项卡，另可返回工作台首页。
- 首页「在线反馈」在已连接和未连接在线协作时均可打开。隔离浏览器模拟首次提交丢失回执，关窗后再次打开仍可读到原稿，再次提交沿用同一请求标识并取得回执。该测试使用合成收件端。管理页在登录后按需展开四个新增表单，展开和收起均未发出写请求。
- 倾听和审议原会在快速选版本时显示较晚到达的旧内容。复验时让第一条详情请求暂停，打开第二个版本后再释放第一条响应。两个页面均继续显示教师最后选择的版本。窄窗还验证了周计划的确认版本、观察记录的历史正文，以及设置中的 AI、游戏配置、备份和反馈入口。
- 审议历史初版只提示保留了结构化文档。另存一条原稿段落、二次稿段落均与表单正文不同的合成记录，回修后在历史页分别展开两份段落，读回与已保存版本一致。倾听历史逐项核对了观察区域、五领域和十五组照片与文字。

最终日历入口通过 Vue 类型检查、Vite 桌面前端源码构建及全部 59 个 D1 前端测试文件。独立编译了本轮变更的 26 个 Python 文件，并实测管理页新增表单展开与收起。

## 已有档案与备份

用迁移前的合成档案从 0021 升至 0022。旧记录首次修改时，保留修改前可读的版本和新保存的版本。倾听覆盖五领域、十五组记录、作品日期、评价及照片。即使当前记录移除照片，原版本仍能读取原始图像。课程审议分别核对原稿、二次稿、字段与随版本保存的结构化内容，并检查记录之间的读取隔离。

对该档案做加密快照，恢复到独立目录并冷启动。最后一轮含 3 个倾听版本、6 个课程审议版本及 6 项资源指纹，其中一个审议版本同时保存了原稿和二次稿的结构化段落。逐项核对恢复前后的历史行及资源指纹一致。针对完整历史、受损内容拒绝、备份、迁移和恢复的联合回归通过 98 项。

倾听、课程审议和学期归属回归通过 208 项及 115 个子用例。首次运行时，两项照片旋转测试使用的简化事务对象缺少新保存步骤所需的记录身份。补全测试边界后，复核了旋转只追加一个版本、原始图片字节保留和提交结果未知时的处理。日计划、周计划相关回归另通过 251 项及 101 个子用例。

观察、在线反馈、迁移及 Word 导出回归通过 286 项及 77 个子用例。两条早期提示词测试还将第二版作为当前默认，已按现行第三版校正，同时继续断言第一版和第二版的历史内容。

Windows 上首次将完整倾听备份用例放在较长的临时根时，创建深层资源临时文件返回了 `BACKUP_PATH_INVALID`。同一用例在独立短路径复验通过，并计入上述 98 项。超长路径仍按已有环境限制记录。

## 在线更新与 WebDAV

- 更新先通过教师提供的加速器下载。独立使用应用下载通道读取了 20261120 版本的 1,765 字节签名清单和 46,279,836 字节 ZIP，两次均通过 `github.ywyz.tech` 取完，SHA-256 与 GitHub 发布资源一致。完整包摘要为 `1930197f9842ff936288ff0a23d7343a094e86a1509d3878f0fee8d57c51b1cd`。加速不可用时可回退官方地址。对发行来源、文件身份、跳转、签名、摘要和大小继续执行原有校验。[在线更新规格](../specs/desktop-application-update.md)
- `data.cstcloud.cn/dav/` 可以直接填入，应用补全 HTTPS 并结合系统及随附公共根证书验证服务器。实测修复前的 Python 握手报证书链不受信，修复后的匿名请求通过证书链和主机名检查并收到 HTTP 401，服务端要求登录。真实账号的登录、上传和恢复留待教师测试。[WebDAV 与在线反馈规格](../specs/desktop-webdav-and-online-feedback.md)
- 在线更新、WebDAV 与相关桌面回归通过 207 项。迁移资源和桌面构建守卫的源码及静态回归通过 150 项。本轮未执行桌面打包、更新安装或线上管理端部署。
