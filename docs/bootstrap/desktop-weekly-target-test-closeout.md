## 两项最小回修

1. **周 Word 四栏合并格宽度。** 旧实现重复计入第一标签列 933，导致四栏右格 `tcW=11052` 与其 `gridSpan` 覆盖的 10119 不一致；旧行总宽为11985，而 grid／表宽为11052。仅将右格标签部分改为920，使右格为 `920+9199=10119`，第一格仍933。未改模板、表总宽、边框、页边距或旧确认数据。新增回归经实际导出链验证五／六／七／零教学日场景；这是一个用例内四种场景，不计成四项独立用例。
2. **范围无匹配的提示。** 零教学日确认不应进入范围导出，旧版已禁止生成，但只显示泛化失败并建议重试。仅在确实无匹配的分支附加 `no_matching_confirmed_weeks`，前端按错误代码＋该 reason 给出明确中文提示，不引导无效重试；普通404、未知错误与网络结果不明的原义保留。新包已实际显示“所选日期范围没有与教学日相交的已确认周计划；零教学日周请单份导出。”，生成禁用；随后更改范围可继续预览并成功导出。

五个实现／测试变更为 [Word 生成器](../../backend/app/services/word_export_docx.py)、[周导出服务](../../backend/app/local/weekly_plan_export_service.py)、[周导出测试](../../backend/tests/local/test_weekly_plan_export.py)、[前端错误投影](../../frontend/src/d1/weekly.ts)及[前端核心测试](../../frontend/src/d1/d1.weekly-core.test.mjs)。
